# 语气风格审查原则

---

## 1. Voice 与 Tone 的区分

- **Voice（品牌声音）**：品牌的一致性人格，不随场景变化。用 3-5 个核心属性定义，是审查的锚点——所有内容应"听起来像同一个品牌在说话"
- **Tone（语气调适）**：声音在不同场景下的表达方式。品牌在语气谱系（严肃↔轻松）上有允许的活动范围，不同内容类型有不同语气区间

---

## 2. 品牌声音属性矩阵

用"是这样/不是那样"框架定义每个属性的正负边界：

```
属性：[专业的]
├── 是这样：术语准确、有依据、逻辑清晰
└── 不是那样：堆砌黑话、居高临下、冷冰冰
```

声音维度量表：

| 维度 | 低端 | 高端 |
|------|------|------|
| 正式度 | 随意口语 | 严格正式 |
| 幽默度 | 严肃庄重 | 风趣诙谐 |
| 热情度 | 克制冷静 | 热情洋溢 |
| 权威度 | 平等对话 | 专家权威 |
| 尊重度 | 直接坦率 | 委婉恭敬 |

---

## 3. 内容类型语气映射

| 内容类型 | 语气倾向 | 关键要求 |
|---------|---------|---------|
| 营销文案 | 热情、鼓舞、简洁 | 突出价值，避免空洞承诺 |
| 产品界面 | 清晰、简洁、引导性 | 行动导向，减少认知负荷 |
| 帮助文档 | 耐心、详尽、支持性 | 步骤清晰，不假设用户知识 |
| 错误提示 | 坦诚、安抚、行动导向 | 说明发生了什么、如何恢复 |
| 社交媒体 | 亲和、及时、个性化 | 符合平台调性，保持品牌底色 |
| 邮件通知 | 专业、简明、尊重 | 重点前置，行动明确 |
| 法律/合规 | 严谨、精确、中立 | 措辞准确，避免歧义 |

偏差判定：合规 → 轻微偏差（略超区间不违背声音）→ 显著偏差（严重偏离影响感知）→ 品牌声音违反（"听起来不像这个品牌"）。

---

## 4. 语言模式审查要点

| 层面 | 审查项 |
|------|--------|
| 词汇 | 品牌术语表用词、禁用词汇、行业术语适度、同一概念统一命名 |
| 句式 | 句子长度偏好、主动/被动语态、人称统一（我们/你/您）、标点风格 |
| 情感 | 情感温度范围、共情表达（错误提示/投诉回复）、激励性语言（成就/完成） |

---

## 5. 多语言与本地化一致性

审查要点：翻译是否保留品牌声音核心属性、语气区间跨语言是否一致、文化敏感性检查、品牌专有名词翻译标准统一。

---

## 6. 审查报告结构

```
1. 审查概述（范围、方法、审查的内容类型）
2. 品牌声音属性定义
3. 声音属性矩阵（是这样/不是那样）
4. 内容类型语气映射
5. 逐项审查发现（按内容类型分组）
6. 语气偏差汇总（按严重度排序）
7. 改进建议与优秀案例
8. 品牌词汇表更新建议（如有）
```
