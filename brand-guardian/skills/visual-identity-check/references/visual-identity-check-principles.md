# 视觉识别检查原则

---

## 1. Logo 使用规范检查

| 检查项 | 要点 |
|--------|------|
| 版本正确性 | 主 Logo / 副 Logo / 图标版 / 横版竖版是否正确 |
| 安全区域 | Logo 周围是否保留规定的最小安全区域（通常 Logo 高度 50%-100%） |
| 最小尺寸 | 是否小于规定的最小使用尺寸 |
| 背景适配 | 深底用反白版、浅底用标准版是否正确 |
| 变形篡改 | 是否被拉伸/旋转/剪裁/添加阴影描边渐变等效果 |
| 共存规则 | 与第三方 Logo 共存时大小关系和间距是否合规 |

常见违规：使用旧版 Logo、比例失真、复杂背景导致辨识度下降、安全区域侵入、颜色随意更改。

---

## 2. 色彩系统检查

| 检查项 | 要点 |
|--------|------|
| 主色精确度 | HEX/RGB 值与规范完全匹配（偏差不超过 ±5） |
| 辅助色 | 是否在品牌色板内选取 |
| 主辅比例 | 通常主色 60%、辅色 30%、点缀色 10% |
| 印刷色值 | 印刷物是否使用 CMYK/Pantone |
| 对比度 | 文字/背景对比度满足 WCAG AA（≥ 4.5:1） |

色彩偏差判定：精确匹配=合规 / 色值差 ≤5=可接受记录 / 色值差 6-20=需修正 / 色值差 >20 或品牌外色彩=必须修正。

---

## 3. 字体与排版规范检查

| 检查项 | 要点 |
|--------|------|
| 字体正确性 | 标题/正文/辅助字体是否为品牌指定字体族 |
| 字体层级 | 标题/副标题/正文/注释字号层级是否合规 |
| 字重使用 | 粗体/常规/细体使用场景是否正确 |
| 行距 | 正文行距在规范范围内（通常 1.4-1.8 倍字号） |
| 字距 | 标题和正文字距是否合规 |
| 对齐方式 | 左对齐/居中/两端对齐是否符合品牌偏好 |
| 字体授权 | 使用的字体是否已获得合法授权 |

跨平台降级：Web（品牌字体→备选系统→通用族）/ 移动端（内嵌或合适替代）/ 印刷（矢量非位图）。

---

## 4. 图像与摄影风格检查

| 检查项 | 要点 |
|--------|------|
| 摄影风格 | 色调/光线/构图是否与品牌指南一致 |
| 滤镜调色 | 是否使用品牌规定的调色方案或预设 |
| 人物形象 | 是否体现品牌倡导的多样性和包容性 |
| 图像质量 | 分辨率/清晰度是否满足使用场景要求 |
| 插画风格 | 线条粗细/色彩/整体风格是否统一 |
| 图标系统 | 线条粗细/圆角/填充方式是否一致 |

图像库管理：集中存放于 DAM、使用授权和有效期标注清晰、过时图像已下线。

---

## 5. 版式与布局规范检查

| 检查项 | 要点 |
|--------|------|
| 栅格系统 | 列数/间距/边距是否遵循品牌规定 |
| 留白规范 | 关键元素间留白是否符合品牌"呼吸感" |
| 视觉层级 | 大小/颜色/位置是否引导正确阅读顺序 |
| 模板一致性 | 同类型材料是否使用统一版式模板 |
| 响应式适配 | 不同屏幕尺寸下布局是否保持一致性 |
| 印刷规范 | 出血/裁切线/安全区域是否正确 |

---

## 6. 检查报告结构

```
1. 检查概述（范围、方法、媒介和渠道）
2. Logo 使用合规报告
3. 色彩系统合规报告
4. 字体与排版合规报告
5. 图像风格合规报告
6. 版式与布局合规报告
7. 视觉偏差清单（按优先级排序）
8. 合规评分总表
9. 修复建议与行动计划
10. 优秀视觉案例展示
```
