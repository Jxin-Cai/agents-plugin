# 品牌一致性审计原则

---

## 1. 品牌资产全量盘点

按渠道逐一列举所有品牌露出点，标注最新更新时间，识别不受品牌指南管控的"孤岛资产"。

| 资产类别 | 盘点内容 |
|---------|---------|
| 视觉资产 | Logo 全套版本、色彩系统、字体文件、图像素材库 |
| 内容资产 | 品牌声音指南、信息架构、Tagline/Slogan、Boilerplate |
| 数字触点 | 官网、App、社交媒体、EDM 模板、数字广告 |
| 实体触点 | 名片、信头纸、宣传册、包装、展会物料 |
| 体验触点 | 客服话术、IVR 语音、聊天机器人、入职流程 |

---

## 2. 一致性评分体系

每个触点按五个维度打分（1-5 分）：

| 维度 | 1 分（严重偏差） | 3 分（部分合规） | 5 分（完全合规） |
|------|----------------|----------------|----------------|
| Logo 使用 | 过时/错误版本 | 版本正确但间距/大小偏差 | 完全符合规范 |
| 色彩合规 | 使用品牌外色彩 | 色值接近但不精确 | HEX/RGB 完全匹配 |
| 字体合规 | 使用未授权字体 | 正确字体但层级混乱 | 字体和层级完全合规 |
| 声音一致 | 语气风格完全不同 | 部分内容偏离品牌声音 | 所有内容风格统一 |
| 信息一致 | 核心信息矛盾 | 表述不同但方向一致 | 关键信息完全对齐 |

综合评级：A 级（90-100%）高度统一 / B 级（70-89%）需关注 / C 级（50-69%）需整改 / D 级（<50%）需重建。

---

## 3. 偏差分类与优先级

| 等级 | 定义 | 示例 |
|------|------|------|
| P0 品牌危机 | 核心识别被破坏 | Logo 篡改、品牌名拼写错误、使用竞品色彩 |
| P1 显著偏差 | 可被用户感知的偏差 | 色值偏差 >10%、未授权字体、语气明显不符 |
| P2 轻微偏差 | 专业人员可识别 | 间距微调、图像风格轻微不符、次要格式不统一 |
| P3 优化建议 | 增强项非合规问题 | 可提升一致性的优化点 |

优先级矩阵：高曝光+高严重=立即修复 / 高曝光+低严重=本月 / 低曝光+高严重=本周 / 低曝光+低严重=下次迭代。

---

## 4. 跨渠道一致性检查

| 渠道 | 检查要点 |
|------|---------|
| 官网 | 首页/关于/产品/博客——统一视觉和内容风格 |
| 社交媒体 | 头像/封面/简介/模板——跨平台一致 |
| 邮件 | EDM/事务性/自动化——遵循品牌视觉和语气 |
| 广告 | 展示/搜索/社交——创意在品牌框架内 |
| 印刷物 | 名片/宣传册/报告——印刷色值校准 |
| 环境 | 办公/展会/门店——空间设计体现品牌调性 |
| 内部对齐 | 品牌指南知晓度、入职培训、审批流程 |

---

## 5. 竞品差异化检查

检查品牌与直接竞品的区分度：视觉风格区分度、品牌声音独特性、色彩辨识度、价值主张差异化。

---

## 6. 审计报告结构

```
1. 审计概述（范围、方法、时间）
2. 品牌资产盘点清单
3. 一致性评分总表
4. 偏差发现清单（按优先级排序）
5. 跨渠道一致性矩阵
6. 竞品差异化分析
7. 整改建议与行动计划
8. 下次审计建议时间
```
