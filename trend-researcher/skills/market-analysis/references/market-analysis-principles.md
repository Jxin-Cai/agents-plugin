# 市场分析原则

---

## 1. Porter 五力模型

| 力量 | 关键评估因素 |
|------|------------|
| 现有竞争强度 | 行业集中度（CR4/HHI）、增长率、固定成本占比、差异化程度、退出壁垒 |
| 新进入者威胁 | 规模经济壁垒（MES）、品牌忠诚/转换成本、资本需求/沉没成本、渠道准入、法规壁垒、网络效应 |
| 替代品威胁 | 替代品性价比、用户切换成本、技术成熟度、跨界替代可能性 |
| 供应商议价能力 | 供应商集中度、投入品差异化、前向整合威胁、替代供应商可获得性 |
| 买方议价能力 | 买方集中度/购买量、产品标准化程度、后向整合威胁、信息透明度 |

**分析方法**：对每个力量评分（强/中/弱），标注关键驱动因素，五力综合评估决定行业利润空间。

---

## 2. PESTEL 宏观环境分析

| 维度 | 关键因素示例 |
|------|------------|
| Political（政治） | 政策法规变化趋势、贸易关税壁垒、政治稳定性/地缘风险 |
| Economic（经济） | GDP/经济周期阶段、利率/通胀水平、汇率/资本市场、行业经济指标 |
| Social（社会） | 人口结构变化（老龄化/城市化）、消费行为偏好、文化趋势/价值观、人才供给 |
| Technological（技术） | 关键技术突破/创新速度、研发/扩散速度、自动化/数字化、技术标准迁移 |
| Environmental（环境） | 环保法规/碳政策、可持续发展要求、气候对供应链影响、ESG 投资趋势 |
| Legal（法律） | 数据隐私法规（GDPR/个保法）、反垄断法、知识产权保护、行业合规 |

**分析方法**：每维度识别 2-3 个关键因素，评估影响方向（利好 ↑ / 利空 ↓ / 中性 →）和时间窗口（短期 ≤1 年 / 中期 1-3 年 / 长期 3 年+）。

## 3. 市场规模估算

- **自上而下（TAM-SAM-SOM）**：TAM（最大可寻址市场）→ SAM（按产品定位和地理范围可触达的市场）→ SOM（短期可获取的市场份额）
- **自下而上**：单客户付费意愿 × 目标客户数 × 渗透率/转化率
- **交叉验证**：两种方法结果应在同一数量级，差异过大需检查假设，每步标注数据来源和估算假设

## 4. 市场生命周期

| 阶段 | 特征 | 关键成功因素 |
|------|------|------------|
| 导入期 | 高增长、低渗透、高不确定性 | 技术领先、市场教育、先发优势 |
| 成长期 | 快速增长、竞争者涌入、标准化 | 规模扩张、渠道建设、品牌塑造 |
| 成熟期 | 增长放缓、高集中度、价格竞争 | 成本效率、差异化、客户留存 |
| 衰退期 | 负增长、退出者增加、利基市场 | 收割策略、利基聚焦、转型 |

**判断依据**：渗透率、增长率变化趋势、新进入者数量、并购频率、技术迭代速度。

---

## 5. 数据来源可靠性层级

| 层级 | 来源类型 | 可靠度 |
|------|---------|--------|
| L1 | 上市公司财报、政府统计、央行报告 | 高 |
| L2 | 行业协会报告、权威咨询机构（Gartner/IDC/McKinsey） | 较高 |
| L3 | 第三方数据平台（Statista/Crunchbase）、媒体深度报道 | 中 |
| L4 | 企业自发布数据、营销材料 | 需验证 |
| L5 | 社交媒体、匿名信息、未经证实传闻 | 低 |

**原则**：关键结论至少需 L2 级别来源支撑，L4-L5 级别数据必须标注"未验证"。
