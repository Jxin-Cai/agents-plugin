# 实验设计原则：样本量与预注册

## 4. 样本量计算

### 核心参数

| 参数 | 符号 | 说明 | 影响 |
|------|------|------|------|
| 显著性水平 | alpha | 一类错误概率 | alpha 越小需样本越大 |
| 检验力 | 1-beta | 检测真实效果的概率 | 检验力越高需样本越大 |
| MDE | delta | 业务有意义的最小变化 | MDE 越小需样本越大 |
| 基线值 | p0/mu0 | 当前指标水平 | 影响方差估计 |
| 方差 | sigma^2 | 指标波动程度 | 方差越大需样本越大 |

### 计算公式

**比例型指标**（转化率等）：
```
n = (Z_alpha/2 + Z_beta)^2 * [p1(1-p1) + p2(1-p2)] / (p1 - p2)^2
```

**连续型指标**（ARPU、时长等）：
```
n = (Z_alpha/2 + Z_beta)^2 * 2 * sigma^2 / delta^2
```

### 方差缩减技术

| 技术 | 原理 | 效果 |
|------|------|------|
| CUPED | 利用实验前用户行为数据作为协变量 | 方差缩减 20-50% |
| 分层分析 | 在分层变量内进行分析 | 减少组间方差 |
| 差分法 | 比较实验前后变化差异而非绝对值 | 减少个体差异影响 |

## 5. 实验时长

### 时长要求

| 维度 | 要求 |
|------|------|
| 统计要求 | 累积足够样本量 |
| 业务周期 | 至少覆盖 1 个完整周（7 天） |
| 行为频率 | 低频行为需覆盖完整行为周期 |

**估算公式**：`实验天数 = ceil(每组样本量 * 组数 / 日均流量)`，向上取整到 7 的倍数。

### 不宜运行时段

- 重大节假日（双十一、春节）——用户行为异常
- 系统大版本发布前后——技术变量失控
- 竞品重大变动期——外部干扰
- 季节性波动窗口（除非季节性是研究对象）

## 6. 预注册

预注册在实验开始前记录假设和分析计划，防止 p-hacking、HARKing、选择性报告。

### 预注册文档必须包含

1. **假设声明**：结构化的可证伪假设
2. **主要指标**：事前确定的核心评判指标（最多 1-2 个）
3. **分析方法**：频率学派/贝叶斯/序贯，具体检验方法
4. **决策规则**：推全/回滚/继续观察的条件
5. **分群分析计划**：事前确定要分析的用户分群
6. **多重比较校正**：多变体或多指标时的校正方法
