# 结果分析原则：统计检验与效果量

## 1. 统计检验框架

### 频率学派（Frequentist）

| 概念 | 定义 | 注意事项 |
|------|------|---------|
| p 值 | 零假设下观察到当前或更极端结果的概率 | **不是**"效果存在的概率" |
| alpha | 事前设定的一类错误允许率（通常 0.05） | 必须事前设定，不能事后调整 |
| 置信区间 | 重复实验多次，95% 的区间会包含真实值 | 宽度反映估计精度 |
| 一类错误 | 无效果时错误宣称有效果（假阳性） | alpha 控制此概率 |
| 二类错误 | 有效果但未检测到（假阴性） | 1-beta 是检验力 |

**检验方法选择**：

| 指标类型 | 推荐检验 | 备注 |
|---------|---------|------|
| 比例型（转化率、点击率） | Z 检验 / 卡方检验 | 大样本等价 |
| 连续型（ARPU、时长） | Welch's t 检验 | 不假设方差相等 |
| 非正态分布 | Mann-Whitney U / 置换检验 | 重尾或偏态分布 |
| 计数型（crash 次数） | 泊松 / 负二项检验 | 计数数据 |

### 贝叶斯方法（Bayesian）

| 概念 | 定义 | 优势 |
|------|------|------|
| 后验概率 | 基于数据更新后的信念 | 直接回答"效果存在的概率" |
| 可信区间 | 真实值落在区间的概率为 95% | 比置信区间更直觉 |
| Bayes Factor | 支持 H1 vs H0 的证据比 | 可量化"无效果"的证据 |
| 预期损失 | 选错方案的预期代价 | 直接支持决策 |

**Bayes Factor 解读**：BF<1 支持零假设 | 1-3 微弱 | 3-10 中等 | 10-30 较强 | >30 很强

### 序贯检验（Sequential Testing）

允许运行中多次查看结果而不膨胀假阳性率。方法：Alpha Spending Function、Always-Valid P-values、mSPRT。适用于需尽早获得结果或设置提前停止规则的场景。

## 2. 效果量评估

p 值只回答"效果是否存在"，不回答"效果有多大"。样本量够大时再小的差异都会显著。

| 效果量 | 计算 | 解读 |
|--------|------|------|
| 相对提升 | (实验-对照)/对照 | "+5% 的相对提升" |
| 绝对提升 | 实验-对照 | "转化率从 10% 到 10.5%" |
| Cohen's d | 差异/合并标准差 | 小(0.2)/中(0.5)/大(0.8) |
| 影响用户数 | 日均用户 x 绝对提升 | "每天多 500 个转化" |
| 收入影响 | 影响用户数 x 客单价 | "年化收入增加 100 万" |

### 业务意义判断

效果量是否有业务意义需考虑：实施成本、机会成本、长期可持续性、用户影响面（高价值 vs 低价值用户）。
