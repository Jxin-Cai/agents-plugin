# 结果分析原则

本文档定义了实验结果分析阶段必须遵循的原则。用这些原则确保分析的严谨性和结论的可信度。

---

## 1. 统计检验框架

### 频率学派（Frequentist）

频率学派是 A/B 测试中最广泛使用的统计框架。

**核心概念**：

| 概念 | 定义 | 注意事项 |
|------|------|---------|
| p 值 | 在零假设成立的前提下，观察到当前或更极端结果的概率 | p 值不是"效果存在的概率"，不能做这种解读 |
| 显著性水平 alpha | 事前设定的一类错误允许率，通常 0.05 | 必须事前设定，不能事后调整 |
| 置信区间 | 如果重复实验多次，95% 的区间会包含真实值 | 区间宽度反映估计的精度 |
| 一类错误 | 没有效果时错误地宣称有效果（假阳性） | alpha 控制了这个概率 |
| 二类错误 | 有真实效果但未能检测到（假阴性） | beta 是二类错误率，1-beta 是检验力 |

**适用场景**：
- 样本量事前计算好，实验运行到预定终点
- 需要严格控制假阳性率的场景
- 需要与行业标准对齐的场景（大部分科技公司使用频率学派）

**检验方法选择**：

| 指标类型 | 推荐检验 | 备注 |
|---------|---------|------|
| 比例型（转化率、点击率） | Z 检验 / 卡方检验 | 大样本时两者等价 |
| 连续型（ARPU、时长） | Welch's t 检验 | 不假设方差相等 |
| 非正态分布 | Mann-Whitney U 检验 / 置换检验 | 重尾分布或偏态分布 |
| 计数型（事件发生次数） | 泊松检验 / 负二项检验 | 如 crash 次数 |

### 贝叶斯方法（Bayesian）

贝叶斯方法提供更直觉的概率化决策。

**核心概念**：

| 概念 | 定义 | 优势 |
|------|------|------|
| 后验概率 | 基于数据更新后的信念（P(H\|D)） | 直接回答"效果存在的概率是多少" |
| 先验 | 实验前对效果的信念分布 | 可融入历史实验知识 |
| 可信区间 | 真实值落在此区间的概率为 95% | 解读比置信区间更直觉 |
| Bayes Factor | 支持 H1 vs H0 的证据比 | 可量化"无效果"的证据强度 |
| 预期损失 | 选错方案的预期代价 | 直接支持决策 |

**Bayes Factor 解读**：

| BF 范围 | 证据强度 |
|---------|---------|
| BF < 1 | 支持零假设（无效果） |
| 1 < BF < 3 | 微弱证据 |
| 3 < BF < 10 | 中等证据 |
| 10 < BF < 30 | 较强证据 |
| BF > 30 | 很强证据 |

**适用场景**：
- 需要在实验过程中持续监测并做早期决策
- 历史上有大量同类实验数据可作为先验
- 业务决策需要概率化表述而非二元的"显著/不显著"

### 序贯检验（Sequential Testing）

允许在实验运行过程中多次查看结果而不膨胀假阳性率。

**核心方法**：
- **Alpha Spending Function**：将 alpha 预算分配到多个检查点（如 O'Brien-Fleming、Pocock）
- **Always-Valid P-values**：任意时刻的 p 值都是有效的
- **混合序贯概率比检验（mSPRT）**：结合贝叶斯和频率学派的优点

**适用场景**：
- 业务需要尽早获得结果（如促销活动期间的快速测试）
- 实验有较高的机会成本，越早决策越好
- 需要设置"提前停止"规则的场景

## 2. 效果量评估

### 为什么效果量比 p 值更重要

p 值只回答"效果是否存在（概率意义上）"，不回答"效果有多大"。样本量足够大时，再小的差异都会显著——但业务上可能毫无意义。

### 效果量指标

| 效果量 | 计算 | 解读 |
|--------|------|------|
| 相对提升（Relative Lift） | (实验-对照) / 对照 | "+5% 的相对提升" |
| 绝对提升（Absolute Lift） | 实验 - 对照 | "转化率从 10% 提升到 10.5%" |
| Cohen's d | 差异 / 合并标准差 | 小(0.2)/中(0.5)/大(0.8) |
| 影响用户数 | 日均用户 x 绝对提升 | "每天多 500 个转化" |
| 收入影响 | 影响用户数 x 客单价 | "年化收入增加 ¥100万" |

### 效果量的业务意义判断

效果量是否有业务意义，不能只看数字大小，还要考虑：

- **实施成本**：为了这个提升需要多大的开发投入？
- **机会成本**：做这个实验意味着放弃做其他实验
- **长期价值**：短期提升是否可持续？
- **用户影响面**：影响多少用户？高价值用户还是低价值用户？

## 3. 置信区间解读

### 正确解读

- "如果重复这个实验 100 次，大约 95 次的置信区间会包含真实效果"
- 区间宽度反映估计精度——越窄说明估计越精确

### 常见误解

| 错误解读 | 正确理解 |
|---------|---------|
| "有 95% 的概率真实值在这个区间里" | 这是贝叶斯可信区间的解读，不是频率学派置信区间 |
| "区间不包含 0 就说明效果很大" | 只能说明效果存在，不能说明效果大 |
| "区间包含 0 就说明没有效果" | 只能说明不能拒绝零假设，不等于证明无效果 |

### 置信区间的决策应用

- CI 完全在正值区域 + 效果量有业务意义 → 推全
- CI 跨越零但偏正 → 增加样本量或运行更长时间
- CI 完全在零附近 → 效果可能不存在
- CI 完全在负值区域 → 实验变化产生了负面效果

## 4. 常见分析陷阱

### 数据窥探（Peeking）

- **问题**：每天查看 p 值，一旦看到 p < 0.05 就停止实验
- **后果**：实际假阳性率远高于 5%（窥探 10 次可达 26%）
- **防范**：使用序贯检验，或严格按预设时长运行

### p-hacking

- **问题**：尝试多种分析方法直到找到显著结果
- **表现**：换分母定义、换时间窗口、排除"异常"数据、事后添加协变量
- **防范**：预注册分析计划，事后分析必须标注为探索性

### 辛普森悖论（Simpson's Paradox）

- **问题**：总体趋势与分群趋势相反
- **示例**：实验组总体转化率高于对照组，但在新用户和老用户中都低于对照组（因为实验组中老用户占比更高）
- **检查**：做分群分析时与总体结论对比

### 新奇效应（Novelty Effect）

- **问题**：用户对任何变化都会产生短期好奇心，导致初期指标提升
- **检查**：比较实验前期和后期的效果，看是否有衰减趋势
- **防范**：实验运行足够长时间，或只看实验后半段数据

### 多重比较膨胀

- **问题**：同时检验多个指标/多个分群，导致假阳性率膨胀
- **校正方法**：

| 方法 | 适用场景 | 严格程度 |
|------|---------|---------|
| Bonferroni | 少量比较，需要严格控制 | 最严格（保守） |
| Holm | Bonferroni 的改进版 | 较严格 |
| Benjamini-Hochberg | 控制 FDR 而非 FWER | 适中 |
| 不校正但标注 | 探索性分析 | 最宽松 |

## 5. 决策框架

### 统计显著性 vs 业务显著性

| | 业务显著 | 业务不显著 |
|--|---------|-----------|
| **统计显著** | 推全 | 效果太小，不值得推全 |
| **统计不显著** | 可能样本不够，延长实验 | 放弃或大幅调整方案 |

### 不确定条件下的决策

当结果处于灰色地带时：

1. **计算预期价值**：推全的期望收益 vs 不推全的期望损失
2. **考虑下行风险**：置信区间下限对应的最差情况可以接受吗？
3. **评估可逆性**：推全后如果效果消失，回滚的成本高吗？
4. **考虑信息价值**：继续实验能获得多少额外信息？值得等待吗？

### 实验知识管理

无论实验结果如何，都应记录：

- **假设**：我们验证了什么假设？
- **结果**：数据说了什么？
- **学习**：我们学到了什么？
- **下一步**：基于此实验，下一个实验应该测试什么？
- **可复现性**：任何人按文档能否重现分析结果？
