# 结果分析原则：陷阱与决策

## 3. 置信区间解读

### 常见误解

| 错误解读 | 正确理解 |
|---------|---------|
| "95% 概率真实值在区间里" | 这是贝叶斯可信区间的解读，非频率学派置信区间 |
| "区间不含 0 说明效果很大" | 只能说明效果存在，不能说明效果大 |
| "区间含 0 说明没有效果" | 不能拒绝零假设 ≠ 证明无效果 |

### 决策应用

| CI 位置 | 建议 |
|---------|------|
| 完全在正值 + 效果量有业务意义 | 推全 |
| 跨越零但偏正 | 增加样本量或延长时间 |
| 完全在零附近 | 效果可能不存在 |
| 完全在负值 | 实验变化产生负面效果 |

## 4. 常见分析陷阱

| 陷阱 | 问题 | 后果 | 防范 |
|------|------|------|------|
| 数据窥探 | 每天看 p 值，p<0.05 即停 | 假阳性率远超 5%（10 次窥探达 26%） | 序贯检验或严格按预设时长 |
| p-hacking | 换分母/时间窗口/排除数据直到显著 | 结论不可复现 | 预注册分析计划 |
| 辛普森悖论 | 总体趋势与分群趋势相反 | 错误结论 | 分群分析与总体对比 |
| 新奇效应 | 用户对变化的短期好奇 | 初期指标虚高 | 运行足够长，看后半段数据 |
| 多重比较膨胀 | 多指标/多分群同时检验 | 假阳性率膨胀 | Bonferroni/Holm/BH 校正 |

### 多重比较校正方法

| 方法 | 适用 | 严格程度 |
|------|------|---------|
| Bonferroni | 少量比较 | 最严格 |
| Holm | Bonferroni 改进 | 较严格 |
| Benjamini-Hochberg | 控制 FDR | 适中 |
| 不校正但标注 | 探索性分析 | 最宽松 |

## 5. 决策框架

### 统计显著性 vs 业务显著性

| | 业务显著 | 业务不显著 |
|--|---------|-----------|
| **统计显著** | 推全 | 效果太小不值得 |
| **统计不显著** | 可能样本不够，延长实验 | 放弃或大幅调整 |

### 不显著结果的区分

| 情况 | 判断依据 | 建议 |
|------|---------|------|
| 检验力不足 | 样本量不够大 | 延长实验或增加流量 |
| 效果不存在 | 检验力充足但效果接近零 | 接受零假设，记录学习 |
| 效果量太小 | 统计显著但业务无意义 | 不推全，记录为知识 |

### 灰色地带决策

1. **计算预期价值**：推全期望收益 vs 不推全期望损失
2. **下行风险**：CI 下限对应的最差情况可接受吗？
3. **可逆性**：推全后回滚成本高吗？
4. **信息价值**：继续实验能获得多少额外信息？

### 实验知识管理

无论结果如何必须记录：假设、结果、学习、下一步、可复现性信息。
