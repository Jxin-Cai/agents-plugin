## Step 1: 确定指标层级

基于实验假设，引导用户按三个层级构建指标：

### 核心指标（Primary Metric）——最多 1-2 个

实验的"判官指标"，用来做最终决策（推全/回滚）。

追问：
- "这个实验最终要用什么指标来判定成功或失败？"
- "如果只能看一个数字做决策，你看哪个？"
- "这个指标是否足够灵敏，能在实验周期内检测到变化？"

### 辅助指标（Secondary Metrics）——2-4 个

帮助理解核心指标变化原因的诊断指标。

追问：
- "核心指标提升了，可能是哪些环节改善导致的？"
- "有没有什么中间步骤的指标可以帮助解释因果链？"

### 护栏指标（Guardrail Metrics）——2-3 个

不应恶化的指标，一旦触发护栏意味着需要紧急审视。

追问：
- "这个实验变化可能带来什么副作用？"
- "哪些指标绝对不能变差？（如加载速度、错误率、客诉率）"
- "护栏指标恶化到什么程度需要立即停止实验？"

**⏸️ 向用户展示指标层级结构并等待确认。**

## Step 2: 精确定义计算口径

对每个指标，逐一确认以下要素：

```markdown
### 指标名称：[中文名] / [英文名或代码名]

- **分子**：[精确定义——什么事件、什么条件]
- **分母**：[精确定义——哪些用户/哪些会话/哪些曝光]
- **时间窗口**：[观测周期——实验期间 / 触发后 N 天 / 首次曝光后 7 天]
- **过滤条件**：[排除哪些数据——机器人、内部用户、异常值]
- **聚合方式**：[均值 / 中位数 / 百分位 / 比率 / 求和]
- **数据源**：[哪个埋点 / 哪张表 / 哪个日志]
```

**关键追问——分母陷阱检查**：

| 陷阱 | 问题 | 示例 |
|------|------|------|
| 分母不一致 | "控制组和实验组的分母定义是否完全相同？" | 曝光口径不同导致分母不可比 |
| 幸存者偏差 | "分母是否只包含了'活下来'的用户？" | 只看完成注册的用户，忽略了注册流程中流失的 |
| 时间窗口偏差 | "分母的时间窗口和分子是否匹配？" | 分母算全天用户，分子只算白天行为 |
| 触发条件偏差 | "分母是否只包含有机会被实验影响的用户？" | 用户未看到变化就被算进了分母 |

**⏸️ 每定义完一个指标，向用户确认后再继续下一个。**

## Step 3: 指标灵敏度评估

对核心指标进行灵敏度检查：

- **波动性**：这个指标的日常波动大吗？波动大意味着需要更大样本量
- **方向性**：指标的变化方向是否与业务价值一致？（有时指标提升反而是坏事）
- **时效性**：指标能在实验周期内观测到变化吗？（如年度续费率不适合做 2 周实验的核心指标）
- **可操控性**：实验干预能直接影响这个指标吗？还是中间隔了太多环节？

如果核心指标灵敏度不够，建议用户：
- 考虑使用更近端的代理指标
- 延长实验时长
- 使用方差缩减技术（CUPED）

**⏸️ 等待用户确认。**

## Step 4: 指标体系一致性检查

检查整个指标体系的一致性：

| 检查项 | 结果 |
|--------|------|
| 核心指标是否直接反映实验假设？ | ✅/❌ |
| 辅助指标是否能解释核心指标的变化原因？ | ✅/❌ |
| 护栏指标是否覆盖了主要副作用风险？ | ✅/❌ |
| 所有指标的分母定义是否一致？ | ✅/❌ |
| 指标之间有没有矛盾或冗余？ | ✅/❌ |
| 多指标情况下是否需要多重比较校正？ | ✅/❌/N/A |

向用户报告检查结果。

## Step 5: 保存产出

将指标定义保存到 `{实验目录}/metrics/metrics-{日期}.md`，包含：
- 指标层级结构（核心/辅助/护栏）
- 每个指标的精确计算口径
- 灵敏度评估结果
- 一致性检查报告

## Step 6: 菜单

使用 `AskUserQuestion` 工具向用户展示以下选项（不要用文本菜单让用户输入序号）：

产出摘要：已定义 [N] 个指标——核心 [a] 个、辅助 [b] 个、护栏 [c] 个。所有指标计算口径已明确。

- **进入结果分析（推荐）** — 如果实验已完成，对数据进行统计检验和效果量评估
- **调整指标定义** — 如果需要修改指标口径或添加新指标
- **回到实验设计** — 如果指标定义过程中发现需要调整实验方案

**⏸️ 停下来等待用户选择。不要自动执行。**

## 完成标准

| 维度 | 合格条件 |
|------|---------|
| 核心指标 | 不超过 2 个，直接反映实验假设 |
| 计算口径 | 每个指标含分子、分母、时间窗口、过滤条件 |
| 分母检查 | 经用户确认，排除幸存者/曝光/时间窗口偏差 |
| 护栏指标 | 覆盖主要副作用风险 |
| 灵敏度 | 核心指标能在实验周期内检测到变化 |
| 一致性 | 指标体系一致性检查通过 |
| 用户确认 | 每步产出经用户确认，菜单后等待输入 |

<IMPORTANT>
本技能完成后，展示菜单并等待用户选择下一步。不要自动执行后续技能。
每个指标必须包含分子、分母、时间窗口、过滤条件、聚合方式、数据源六要素，缺任何一项不可标记为"定义完成"。
分母定义必须经过四项陷阱检查（幸存者偏差、曝光偏差、时间窗口偏差、新老混淆），检查结果向用户逐项报告。
核心指标最多 2 个，超出时必须引导用户取舍，不可全部保留。
</IMPORTANT>
