# 指标定义原则：陷阱与灵敏度

## 3. 分母陷阱

分母定义是指标中最容易出错、影响最大的环节。

| 陷阱 | 问题 | 示例 | 检查方法 |
|------|------|------|---------|
| 幸存者偏差 | 分母只含"活到某环节"的用户 | 计算注册完成率时遗漏中途流失用户 | 分母应从最早触发点开始 |
| 曝光偏差 | 用户被分组但未看到变化却算入分母 | 改结账页但用户未到达结账页 | 区分 ITT 和 Per-Protocol |
| 时间窗口偏差 | 分子和分母时间窗口不匹配 | 分母算全天用户，分子只算白天行为 | 确保时间窗口定义一致 |
| 新/老混淆 | 新老用户混合计算但行为模式不同 | 实验组分到更多新用户拉低指标 | 考虑分层分析或标注用户类型 |

## 4. 指标灵敏度

### 评估框架

| 维度 | 要求 | 检查方法 |
|------|------|---------|
| 波动性 | 日常波动不应过大 | 查看历史 CV（标准差/均值） |
| 方向性 | 变化方向与业务价值一致 | 指标上升是否真的业务变好？ |
| 时效性 | 实验周期内能观测到变化 | 行为频率 vs 实验时长 |
| 可归因性 | 实验干预能直接影响 | 干预到指标隔了几个环节？ |

### 灵敏度不足的应对

| 问题 | 解决方案 |
|------|---------|
| 波动太大 | CUPED 方差缩减、对数变换、截尾处理 |
| 行为频率太低 | 使用更近端的代理指标 |
| 因果链太长 | 使用更贴近干预的中间指标 |
| 样本量不够 | 延长实验时长或缩小 MDE |

### 近端 vs 远端指标

`干预 → 近端指标(灵敏高) → 中端指标(建议核心) → 远端指标(业务价值高)`

## 5. 指标体系构建

### 指标树方法

从终极业务目标逐层拆解，选择与实验假设最相关的层级作为核心指标。

### 指标间关系

| 关系 | 说明 |
|------|------|
| 互斥 | A 和 B 不可能同时提升（如低价下客单价与订单量） |
| 因果 | A 提升导致 B 提升（点击率→转化率） |
| 相关 | 同时变化但非因果（可能有共同原因） |
| 零和 | 实验只在不同指标间重新分配（如首页改版改变流量分配） |

### 多重比较校正

| 指标数 | 未校正假阳性率 | 建议方法 |
|--------|-------------|---------|
| 1 | 5% | 无需校正 |
| 3 | 14.3% | Holm 校正 |
| 5 | 22.6% | Benjamini-Hochberg |
| 10 | 40.1% | 必须校正或事前指定唯一核心指标 |

**最佳实践**：事前指定 1 个核心指标不校正，其他指标全部做 FDR 校正。
