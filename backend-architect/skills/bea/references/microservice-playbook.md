# 微服务架构设计 Playbook

---

## 适用场景
从单体拆分或新建微服务架构时使用。

---

## 执行步骤

### 1. 领域边界识别
- 用事件风暴或用例分析划分限界上下文
- 每个上下文 → 一个候选微服务
- 输出：服务清单（名称 + 职责 + 核心实体）

### 2. 服务通信设计
| 通信类型 | 适用场景 | 注意点 |
|----------|---------|--------|
| 同步 REST/gRPC | 查询、强一致性 | 超时策略、重试策略 |
| 异步消息 | 事件驱动、最终一致性 | 幂等消费、死信队列 |
| 编排/编导 | 跨服务事务 | Saga 补偿机制 |

### 3. 数据隔离策略
- 每个服务独立数据库（Database per Service）
- 跨服务查询用 API 组合或 CQRS
- 数据一致性策略（事件溯源 / Saga / 双写）

### 4. 部署与可观测性
- 容器化 + CI/CD 管道
- 分布式追踪（Jaeger/Zipkin）
- 统一日志聚合
- 健康检查 + 熔断 + 限流

---

## 质量门控
- [ ] 服务边界无循环依赖
- [ ] 每个服务有独立部署能力
- [ ] 服务间通信有超时和重试策略
- [ ] 数据一致性策略明确
- [ ] 可观测性覆盖关键链路

---

## 产出
