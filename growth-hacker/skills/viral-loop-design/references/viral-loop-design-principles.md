# 病毒循环设计原则与方法论

## 一、K-factor 计算

**基础公式**：K = i x c（i = 人均邀请数，c = 邀请转化率）

**细化公式**：K = (R x I) x (D x O x L x A)

| 参数 | 含义 | 说明 |
|------|------|------|
| R | 推荐参与率 | 发起推荐行为的用户比例 |
| I | 人均邀请数 | 每个推荐者发出的邀请数 |
| D | 到达率 | 邀请成功送达的比例 |
| O | 打开率 | 被邀请人查看邀请的比例 |
| L | 落地转化率 | 查看邀请→完成注册 |
| A | 激活率 | 注册→完成关键行为 |

### K-factor 解读

| K 值 | 含义 | 增长效果 |
|------|------|---------|
| > 1.0 | 病毒增长 | 指数级增长，无需额外获客支出 |
| 0.5-1.0 | 助力增长 | 有效降低 CAC，需配合付费获客 |
| 0.3-0.5 | 轻度传播 | 有口碑效应，补充获客 |
| < 0.3 | 传播不足 | 需大幅优化或调整策略 |

**敏感度分析**：固定其他参数，逐一提升 50%，对比 K 值变化找最大杠杆。D 已接近上限时杠杆最低，优先优化实施成本最低的环节。

## 二、四类病毒循环模式

| 模式 | 机制 | 经典案例 | 适用产品 |
|------|------|---------|---------|
| 邀请奖励型 | 推荐/被推荐人获奖励 | Dropbox（双方各 500MB）、Uber | 有明确额度的 SaaS/订阅服务 |
| 内容共享型 | 使用中产生可分享内容 | TikTok（带水印）、Canva | 内容创作工具、社交平台 |
| 协作价值型 | 核心功能需多人参与 | Slack、Zoom、Google Docs | 协作工具、团队软件 |
| 社交证明型 | 使用行为被社交圈看到 | LinkedIn、Strava、Hotmail 签名 | 社交属性强、有身份标识的产品 |

**邀请奖励型要点**：奖励关联核心价值、双边 > 单边（转化率高 25-40%）、即时可感知、设上限防薅。
**内容共享型要点**：内容有独立价值、携带品牌标识、一键分享、非用户有注册引导。
**协作价值型要点**：邀请是核心路径而非额外动作、无需注册即可体验、参与→注册路径短。

## 三、推荐计划设计原则

| 原则 | 要点 |
|------|------|
| 最小阻力 | 推荐 < 3 步、多渠道分享、预填文案 |
| 双边价值 | 推荐人"值得行动"、被推荐人"值得注册"、双边比单边转化率高 25-40% |
| 即时反馈 | 状态实时可追踪、奖励 < 24h 到账、里程碑庆祝 |
| 社交认同 | 排行榜、成就徽章、"XX 位朋友已在使用" |

### 高转化触发时机

| 时机 | 原因 |
|------|------|
| Aha Moment 后 | 刚体验核心价值，热情最高 |
| 完成关键任务后 | 成就感驱动分享 |
| NPS 9-10 分用户 | 已是推荐者 |
| 续费/升级时 | 产品认可度高 |

避免在：遇到错误、首次使用未体验价值、付费弹窗同时出现时触发。

### 反欺诈策略

| 风险 | 防范 |
|------|------|
| 自推自 | 设备指纹 + 同 IP 限制 |
| 批量刷单 | 每日上限 + 异常检测 |
| 推荐后流失 | 被推荐人需激活才发奖励 |
| 薅羊毛团伙 | 链式深度限制 + 奖励递减 |

## 四、K > 1.0 实现路径

| 路径 | 关键指标 | 案例 |
|------|---------|------|
| 协作内生型（最可靠） | 每新用户邀请 3+，转化率 40%+ | Slack 早期 |
| 内容爆发型（不稳定） | 分享率 30%+，点击率 10%+ | TikTok、Wordle |
| 激励驱动型（需持续投入） | 参与率 25%+，每人邀请 5+ | Dropbox、PayPal |
| 复合增长型（最现实） | 多机制组合，单项 K=0.3-0.5 | 产品分享 + 推荐 + 内容 + 证明 |

优化节奏：Phase1(0-30d) K=0.1-0.2 → Phase2(30-90d) K=0.3-0.5 → Phase3(90-180d) K=0.5-0.8 → Phase4(180d+) 冲刺 K>0.8。
