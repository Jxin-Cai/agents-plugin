# 看板度量与卡片原则

---

## 1. 卡片（Card）配置

必须显示：Issue Key、标题、经办人头像、优先级图标、问题类型图标
建议显示：故事点/估算、标签、到期日、停留天数

### 颜色编码

| 颜色 | 含义 |
|------|------|
| 红色 | 超过 SLA 或被阻塞 |
| 黄色 | 接近 SLA 或高优先级 |
| 绿色 | 正常流转 |
| 灰色 | 低优先级或暂停 |

老化指示：卡片在同一列停留超过 N 天变色提醒，N 参考团队平均周期时间。

---

## 2. 度量与仪表盘

### 核心度量

| 指标 | 定义 | 用途 | 目标 |
|------|------|------|------|
| 前置时间 | Issue 创建到关闭的总时间 | 衡量客户等待 | 持续缩短 |
| 周期时间 | Issue 开始处理到完成 | 衡量处理效率 | 稳定可预测 |
| 吞吐量 | 单位时间完成数 | 衡量产出能力 | 稳定或提升 |
| CFD | 各状态数量随时间累积变化 | 可视化瓶颈 | 带宽均匀 |

### 仪表盘配置

| 受众 | 推荐组件 |
|------|---------|
| 团队日常 | CFD + 周期时间分布 + WIP 监控 |
| 管理层 | 吞吐量趋势 + SLA 达成率 + Bug 趋势 |
| 回顾会 | 周期时间变化 + WIP 违规次数 + 阻塞原因分布 |

### 度量反模式
- 不用度量考核个人——度量是发现系统问题
- 不追求所有指标同时优化——选 1-2 个最重要的
- 不在无上下文时对比不同团队度量

---

## 3. 过滤器与快速视图

常用过滤器：我的工作、阻塞中、即将到期（3 天内）、无人认领、僵尸卡片（14 天未更新）

快速筛选按钮：按 Sprint、按经办人、按问题类型、按标签、按组件
