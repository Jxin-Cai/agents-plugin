# 引用审计原则

本文档定义了 AI 引用审计阶段必须遵循的方法论和标准。

---

## 1. Prompt 设计原则

### 设计目标
测试 prompt 必须模拟真实用户在 AI 平台上的自然查询行为，覆盖品牌被发现的所有关键场景。

### Prompt 分类体系

#### 推荐型（Recommendation）
用户直接寻求推荐时的查询模式：
- "最好的 {品类} 是什么"
- "推荐一个适合 {场景} 的 {品类}"
- "{年份} 年最值得用的 {品类}"
- "有哪些好用的 {品类} 工具"
- "{目标受众} 应该用什么 {品类}"

**设计要点**：覆盖泛品类查询和细分场景查询，包含带年份和不带年份的变体。

#### 比较型（Comparison）
用户在多个选项间做决策时的查询模式：
- "{品牌A} vs {品牌B}"
- "{品牌A} 和 {品牌B} 哪个好"
- "{品牌A} 和 {品牌B} 对比"
- "{品牌A} 的替代品有哪些"
- "类似 {竞品} 但更 {差异化特征} 的工具"

**设计要点**：覆盖品牌与每个核心竞品的两两对比，以及替代品查询。

#### 教程型（Tutorial/How-to）
用户寻求使用指导时的查询模式：
- "如何用 {品类} 做 {任务}"
- "{品类} 入门指南"
- "{品类} 最佳实践"
- "怎么从 {竞品} 迁移到 {品类}"
- "{品类} 常见问题"

**设计要点**：覆盖品牌核心功能的使用场景和常见问题。

#### 最佳选择型（Best-of/Ranking）
用户寻求排名或精选列表时的查询模式：
- "{年份} 年 {品类} 排行榜"
- "{品类} Top 10"
- "{行业} 最佳 {品类} 工具"
- "企业级 {品类} 推荐"
- "{地区} 最受欢迎的 {品类}"

**设计要点**：覆盖不同维度的排名查询（年份、地区、受众类型）。

### Prompt 变体规则
每个核心 prompt 应考虑以下变体：
- **含品牌名 vs 不含品牌名**：测试品牌知名度对引用的影响
- **通用 vs 细分**：如"最好的 CRM" vs "最好的小企业 CRM"
- **中文 vs 英文**：如果品牌面向多语言市场

## 2. 各平台引用行为差异

### ChatGPT (OpenAI)
- **引用偏好**：偏好知名品牌、权威来源网站的内容
- **引用格式**：通常以推荐列表形式呈现，附带简短描述
- **关键信号**：FAQ Schema、清晰的 H2/H3 标题结构、Google 搜索排名高的页面
- **更新节奏**：知识库有截止日期，但联网模式下可获取最新信息
- **注意事项**：对有争议的推荐会给出多个选项，倾向于平衡展示

### Claude (Anthropic)
- **引用偏好**：偏好内容准确度和技术深度
- **引用格式**：倾向于详细的分析和对比，不简单列清单
- **关键信号**：内容的事实准确性、技术细节完整度、逻辑自洽性
- **更新节奏**：有训练数据截止日期，依赖搜索工具获取最新信息
- **注意事项**：更倾向于给出有条件的推荐（"如果你需要X，那么A更好；如果你需要Y，那么B更好"）

### Gemini (Google)
- **引用偏好**：强烈偏好 Google 生态内的结构化数据
- **引用格式**：常引用 Google 搜索结果、Knowledge Graph 实体
- **关键信号**：Google Business Profile、Schema Markup、Knowledge Panel、内容时效性
- **更新节奏**：实时联网，内容新鲜度是重要因素
- **注意事项**：对 Google 自有服务和合作伙伴可能有隐性偏好

### Perplexity
- **引用偏好**：最注重可溯源性，所有引用必须有明确的 URL 来源
- **引用格式**：带脚注编号的引用，每条引用对应具体来源页面
- **关键信号**：页面可抓取性、内容结构化程度、来源权威度
- **更新节奏**：实时联网搜索，时效性非常重要
- **注意事项**：引用来源可见，是检验"为什么被引用"的最佳平台

## 3. 评分标准

### 引用率（Citation Rate）
```
引用率 = 被引用的查询数 / 总查询数 x 100%
```
- **优秀**：> 60%
- **良好**：40-60%
- **需改进**：20-40%
- **紧急**：< 20%

### SOV（Share of Voice）
```
SOV = 品牌被引用次数 / 所有品牌在相同查询中被引用总次数 x 100%
```
SOV 反映品牌在 AI 推荐中的"声量份额"。与搜索引擎 SEO 的 SOV 概念类似，但统计的是 AI 生成内容中的品牌出现频率。

### 引用质量评级

| 级别 | 定义 | 权重 |
|------|------|------|
| 第一推荐 | 品牌作为首要推荐出现 | 3x |
| 列表引用 | 品牌出现在推荐列表中（非首位） | 2x |
| 仅提及 | 品牌被提到但不是推荐重点 | 1x |
| 未引用 | 品牌完全未出现 | 0x |

### 引用 Gap 计算
```
引用 Gap = 竞品最高引用率 - 自身引用率
```
Gap 为正值表示落后于竞品，数值越大越需要优先优化。

## 4. 数据记录模板

### 单条查询记录

```markdown
### Prompt: "{查询内容}"
- 类别：推荐型 / 比较型 / 教程型 / 最佳选择型
- 查询日期：{YYYY-MM-DD}

| 平台 | 引用状态 | 引用位置 | 竞品引用 | 来源 URL |
|------|---------|---------|---------|---------|
| ChatGPT | 引用/未引用 | 第一推荐/列表/仅提及/未出现 | {竞品A, 竞品B} | - |
| Claude | ... | ... | ... | - |
| Gemini | ... | ... | ... | - |
| Perplexity | ... | ... | ... | {URL1, URL2} |

备注：{任何值得记录的观察，如回复中对品牌的描述是否准确}
```

### 汇总 Scorecard 模板

```markdown
## Citation Audit Scorecard — {品牌名} — {日期}

### 审计概要
- 品牌：{品牌名}
- 类别：{产品类别}
- 竞品：{竞品列表}
- 测试 Prompt 数：{N}
- 覆盖平台：{平台列表}

### 总体评分
- 引用率：{X%} ({评级})
- 第一推荐率：{X%}
- SOV：{X%}（排名第 {R}/{总品牌数}）

### 平台维度分析
(按平台展示引用率、SOV、引用质量)

### Prompt 类别维度分析
(按四个类别展示引用率、最强竞品、Gap)

### 关键发现
1. {发现1}
2. {发现2}
3. {发现3}

### 高优先级缺失查询
(列出引用 Gap 最大的 5-10 个查询)
```
