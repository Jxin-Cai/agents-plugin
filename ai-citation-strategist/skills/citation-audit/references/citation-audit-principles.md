# 引用审计原则

---

## 1. Prompt 设计原则

测试 prompt 必须模拟真实用户查询行为，覆盖品牌被发现的所有关键场景。

### Prompt 分类体系

| 类别 | 查询模式示例 | 设计要点 |
|------|------------|---------|
| 推荐型 | "最好的 {品类}" "推荐一个 {品类}" "{年份} 最值得用的 {品类}" | 覆盖泛品类和细分场景，含/不含年份变体 |
| 比较型 | "{A} vs {B}" "{A} 的替代品" "类似 {竞品} 但更 {特征}" | 覆盖两两对比 + 替代品查询 |
| 教程型 | "如何用 {品类} 做 {任务}" "{品类} 入门指南" "{品类} 最佳实践" | 覆盖核心功能使用场景和常见问题 |
| 最佳选择型 | "{年份} {品类} 排行" "{品类} Top 10" "{行业} 最佳 {品类}" | 覆盖不同维度排名（年份、地区、受众） |

### 推荐型详细模式
- "最好的 {品类} 是什么"
- "推荐一个适合 {场景} 的 {品类}"
- "{目标受众} 应该用什么 {品类}"
- "有哪些好用的 {品类} 工具"

### 比较型详细模式
- "{品牌A} vs {品牌B}" / "{品牌A} 和 {品牌B} 哪个好"
- "{品牌A} 的替代品有哪些"
- "类似 {竞品} 但更 {差异化特征} 的工具"

### 教程型详细模式
- "如何用 {品类} 做 {任务}" / "{品类} 入门指南"
- "怎么从 {竞品} 迁移到 {品类}"
- "{品类} 常见问题"

### 最佳选择型详细模式
- "{年份} 年 {品类} 排行榜" / "{品类} Top 10"
- "{行业} 最佳 {品类} 工具" / "企业级 {品类} 推荐"

### Prompt 变体规则
- **含品牌名 vs 不含品牌名**：测试品牌知名度对引用的影响
- **通用 vs 细分**：如"最好的 CRM" vs "最好的小企业 CRM"
- **中文 vs 英文**：如果品牌面向多语言市场

## 2. 评分标准

### 引用率（Citation Rate）

`引用率 = 被引用的查询数 / 总查询数 x 100%`

| 评级 | 范围 |
|------|------|
| 优秀 | > 60% |
| 良好 | 40-60% |
| 需改进 | 20-40% |
| 紧急 | < 20% |

### SOV（Share of Voice）

`SOV = 品牌被引用次数 / 所有品牌在相同查询中被引用总次数 x 100%`

### 引用质量评级

| 级别 | 定义 | 权重 |
|------|------|------|
| 第一推荐 | 品牌作为首要推荐出现 | 3x |
| 列表引用 | 出现在推荐列表中（非首位） | 2x |
| 仅提及 | 被提到但不是推荐重点 | 1x |
| 未引用 | 完全未出现 | 0x |

### 引用 Gap

`Gap = 竞品最高引用率 - 自身引用率`

Gap 为正值表示落后于竞品，数值越大越需要优先优化。
