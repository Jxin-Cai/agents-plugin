# 引用审计

用户传入的参数：`$ARGUMENTS`

---

## 加载引用

使用 Read 工具加载以下引用文件，严格遵守其中所有规则：

- `references/citation-audit-principles.md` — Prompt 设计原则、评分标准
- `references/citation-audit-templates.md` — 各平台差异、数据记录模板

---

## 强制执行规则

- **绝不** 在没有用户提供品牌信息的情况下编造引用数据
- 每条引用记录必须标注查询平台、查询日期和结果状态
- AI 查询结果具有非确定性，同一 prompt 多次查询可能有不同结果，需标注
- 联网搜索获取的数据必须标注来源和时间

---

## 前置条件

确定当前工作目录：检查 `_ai-citation/` 下最近创建的日期目录。若无，询问用户品牌简写并创建 `_ai-citation/{当前日期}-{任务简写}/` 目录结构。

加载以下上下文（如果存在）：
- `{工作目录}/context/**` — 已有的品牌上下文（品牌信息、竞品列表）
- 当前对话中已有的讨论

---

## Step 1: 锚定审计范围

如果 `$ARGUMENTS` 非空，以此作为审计范围的初始输入。

引导用户明确以下锚点：

- **品牌/产品**：审计的目标品牌或产品是什么？
- **主域名**：品牌官网 URL
- **产品类别**：属于什么行业/品类？（如 CRM SaaS、电商平台、健康科技）
- **核心竞品**：3-5 个直接竞品（需要对比引用情况的对象）
- **目标受众**：品牌的典型用户画像（用于设计 prompt）
- **审计目标平台**：默认覆盖 ChatGPT、Claude、Gemini、Perplexity，用户可调整

将回答记录到 `{工作目录}/context/audit-scope.md`。

**暂停 等待用户确认后继续。**

## Step 2: 设计测试 Prompt

按照 `references/citation-audit-principles.md` 第 1 节的 prompt 设计原则，为目标品类生成 20-40 个测试 prompt。

按四个类别分组：

| 类别 | 说明 | 示例数量 |
|------|------|---------|
| 推荐型 | "最好的 XX 是什么" "推荐一个 XX" | 8-12 个 |
| 比较型 | "A vs B" "XX 和 YY 哪个好" | 6-10 个 |
| 教程型 | "如何用 XX 做 YY" "XX 入门指南" | 4-8 个 |
| 最佳选择型 | "XX 行业最佳工具" "2026 年 XX 排行" | 4-8 个 |

每个 prompt 需要：
1. 模拟真实用户的自然语言表达
2. 覆盖品牌核心功能和使用场景
3. 包含品牌名和不含品牌名的变体

向用户展示 prompt 清单，确认是否需要增删调整。

**暂停 等待用户确认后继续。**

## Step 3: 执行多平台查询

对每个确认的测试 prompt，在目标平台上查询并记录：

对每个 prompt：
1. 记录 AI 回复中是否提及目标品牌（引用/未引用）
2. 记录品牌在回复中的位置（第一推荐 / 列表中 / 仅提及 / 未出现）
3. 记录同一 prompt 下哪些竞品被引用
4. 记录回复中引用的来源 URL（如有）

**每完成 5-8 个 prompt 的查询：**
- 向用户展示阶段性结果
- 确认是否继续

**暂停 每批次完成后等待用户确认。**

- SOV（Share of Voice）：{品牌引用次数}/{所有品牌总引用次数} = {百分比}

**暂停 等待用户确认后继续。**

## Step 5: 保存产出

将引用审计报告保存到 `{工作目录}/audit/citation-audit-{日期}.md`，包含：
- 审计范围和品牌信息
- 测试 prompt 完整清单
- 逐条查询结果记录
- Citation Audit Scorecard
- 竞品 SOV 排名

## Step 6: 菜单

使用 `AskUserQuestion` 工具向用户展示以下选项（不要用文本菜单让用户输入序号）：

产出摘要：完成 {N} 个 prompt 在 {M} 个平台的引用审计。品牌整体引用率 {X%}，SOV 排名第 {R}。发现 {G} 个引用缺失的高价值查询。

- **进入丢失查询分析（推荐）** — 深入分析竞品赢因和引用缺失原因
- **补充引用审计** — 增加测试 prompt 或覆盖更多平台
- **直接生成修复方案** — 如果缺失模式已经清晰

**暂停 停下来等待用户选择。不要自动执行。**

---

## 产出验收标准

| 维度 | 合格条件 |
|------|---------|
| 审计范围 | 品牌、竞品、类别、平台均已锚定 |
| Prompt 覆盖 | 四个类别均有，总量 20-40 个 |
| 查询记录 | 每个 prompt 在各目标平台有记录，含位置、竞品引用、来源 URL |
| Scorecard | 包含引用率、SOV、平台维度和类别维度 |
| 数据标注 | 每条记录标注查询日期和平台 |

本技能完成后，展示菜单并等待用户选择下一步。不要自动执行后续技能。
