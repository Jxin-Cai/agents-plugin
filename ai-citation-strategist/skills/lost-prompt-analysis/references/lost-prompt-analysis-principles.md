# 丢失查询分析原则

---

## 1. 丢失分类方法

| 丢失类型 | 定义 | 特征 | 紧急度 |
|---------|------|------|--------|
| 完全缺失 | 所有平台均未引用，竞品被引用 | 严重内容缺口或实体信号缺失 | 高——优先修复 |
| 竞品领先 | 有引用但排位低于竞品 | 内容深度不足或权威度差距 | 中——优化 ROI 高 |
| 平台差异 | 部分平台引用，其他缺失 | 特定平台优化缺失（如缺 Google 结构化数据） | 中——针对性修复效率高 |

---

## 2. 竞品赢因分析框架

对每个丢失查询，从四个维度分析竞品为什么被 AI 推荐：

### 内容格式与结构
- **专题覆盖**：竞品是否有专门的 FAQ 页、比较页、深度指南？
- **标题结构**：H1/H2/H3 是否清晰回应用户查询意图？
- **内容密度**：前 200 字是否直接回答核心问题？（AI 倾向提取开头内容）
- **列表/表格**：是否使用结构化列表或对比表格？（AI 偏好可提取的结构化内容）
- **更新频率**：内容最近更新时间？（尤其影响 Gemini 和 Perplexity）

### Schema Markup 与结构化数据
- **FAQ Schema**：是否部署 FAQPage Schema？（直接影响 FAQ 类查询引用）
- **Product Schema**：名称、描述、评分、价格是否完整？
- **Review/Rating Schema** / **Organization Schema** / **HowTo Schema** / **BreadcrumbList**

### 实体信号强度
- **Knowledge Graph**：品牌是否有实体？品牌名搜索是否触发 Knowledge Panel？
- **百科词条**：是否有 Wikipedia/Wikidata 或其他权威百科词条？
- **实体关联**：品牌与行业、品类、创始人等实体的关联强度？
- **社交验证**：各平台是否有经过验证的官方账号？

### 来源权威度
- **自有网站引用**：AI 引用竞品时是否直接引用其官网？
- **第三方评测**：是否被 G2、Capterra、TrustRadius 等高度评分？
- **行业媒体**：是否频繁被行业媒体报道？
- **反向链接**：页面外部链接的数量和质量？

---

## 3. 优先级评估模型

### 影响面评分（Impact, 1-5）

| 分值 | 定义 |
|------|------|
| 5 | 核心品类查询，高搜索量，直接影响获客 |
| 4 | 重要品类查询，中等搜索量，影响品牌认知 |
| 3 | 次要品类查询或特定细分场景 |
| 2 | 长尾查询，低搜索量但有转化潜力 |
| 1 | 边缘查询，影响有限 |

### 修复难度评分（Effort, 1-5）

| 分值 | 定义 |
|------|------|
| 1 | 快速修复：添加 Schema、更新现有内容 |
| 2 | 小幅修复：优化内容结构、增加 FAQ |
| 3 | 中等工程：创建新专题内容页面 |
| 4 | 较大工程：建设第三方评测和反向链接 |
| 5 | 长期工程：建立实体信号、提升整体权威度 |

### 优先级计算

`优先级分 = 影响面评分 x (6 - 修复难度评分)`

| 优先级 | 分值范围 | 行动 |
|--------|---------|------|
| P0 | >= 20 | 立即修复 |
| P1 | 15-19 | 本周内修复 |
| P2 | 10-14 | 两周内修复 |
| P3 | < 10 | 排入后续计划 |

### 跨平台权重调整
- 单平台缺失：按原始优先级
- 两个平台缺失：优先级 +5 分
- 三个及以上平台缺失：优先级 +10 分
