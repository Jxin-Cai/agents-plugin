# 丢失查询分析原则

本文档定义了 Lost Prompt Analysis 阶段必须遵循的分析原则和框架。

---

## 1. 丢失分类方法

### 完全缺失（Total Absence）
品牌在所有目标 AI 平台的回复中均未出现，而一个或多个竞品被明确引用。

**特征**：
- 所有平台引用状态为"未引用"
- 至少一个竞品在至少一个平台被引用
- 通常指向严重的内容缺口或实体信号缺失

**紧急度**：高 — 需要优先修复，因为代表品牌在该查询场景完全不可见。

### 竞品领先（Competitor Dominance）
品牌在部分平台有引用，但始终排在竞品之后；或者品牌仅被"提及"而竞品是"推荐"。

**特征**：
- 品牌引用质量低于竞品（如仅提及 vs 第一推荐）
- 在多个平台中竞品一致性地排在品牌前面
- 通常指向内容深度不足或权威度差距

**紧急度**：中 — 有基础但需要提升，优化 ROI 通常较高。

### 平台差异（Platform Disparity）
品牌在某些平台被良好引用，但在其他平台缺失。

**特征**：
- 平台间引用表现差异大（如 ChatGPT 引用但 Gemini 不引用）
- 通常指向特定平台的优化缺失（如缺少 Google 结构化数据导致 Gemini 不引用）
- 修复通常有明确的技术方向

**紧急度**：中 — 针对性修复效率高，通常是技术优化而非内容重写。

## 2. 竞品赢因分析框架

对每个丢失的查询，从四个维度分析竞品为什么被 AI 推荐：

### 内容格式与结构
- **专题覆盖**：竞品是否有专门针对该查询主题的内容页面？（如独立的 FAQ 页、比较页、深度指南）
- **标题结构**：H1/H2/H3 层级是否清晰地回应了用户查询意图？
- **内容密度**：内容是否在前 200 字内直接回答核心问题？（AI 倾向提取开头内容）
- **列表/表格**：是否使用了结构化的列表或对比表格？（AI 偏好可提取的结构化内容）
- **更新频率**：内容最近更新时间？（尤其影响 Gemini 和 Perplexity）

### Schema Markup 与结构化数据
- **FAQ Schema**：是否部署了 FAQPage Schema？（直接影响 AI 对 FAQ 类查询的引用）
- **Product Schema**：是否有完整的 Product Schema（名称、描述、评分、价格）？
- **Review/Rating Schema**：是否有用户评价的结构化数据？
- **Organization Schema**：是否有完整的组织信息 Schema？
- **HowTo Schema**：教程类内容是否部署了 HowTo Schema？
- **BreadcrumbList**：是否有面包屑导航 Schema（帮助 AI 理解内容层级）？

### 实体信号强度
- **Knowledge Graph 存在**：品牌是否在 Google Knowledge Graph 中有实体？
- **Knowledge Panel**：品牌名搜索是否触发 Knowledge Panel？
- **维基百科/百科词条**：品牌是否有维基百科或其他权威百科词条？
- **实体关联**：品牌实体与行业、品类、创始人等实体的关联强度？
- **社交媒体验证**：品牌在各社交平台是否有经过验证的官方账号？

### 来源权威度
- **自有网站引用**：AI 引用竞品时是否直接引用其官网内容？
- **第三方评测**：竞品是否被权威第三方（G2、Capterra、TrustRadius 等）高度评分？
- **行业媒体**：竞品是否频繁被行业媒体报道和引用？
- **学术/研究引用**：竞品是否被学术论文或行业研究报告引用？
- **反向链接**：竞品页面的外部链接数量和质量？

## 3. 优先级评估模型

### 影响面评分（Impact Score, 1-5）

| 分值 | 定义 |
|------|------|
| 5 | 核心品类查询，高搜索量，直接影响获客 |
| 4 | 重要品类查询，中等搜索量，影响品牌认知 |
| 3 | 次要品类查询或特定细分场景 |
| 2 | 长尾查询，低搜索量但有转化潜力 |
| 1 | 边缘查询，影响有限 |

### 修复难度评分（Effort Score, 1-5）

| 分值 | 定义 |
|------|------|
| 1 | 快速修复：添加 Schema Markup、更新现有内容 |
| 2 | 小幅修复：优化内容结构、增加 FAQ 板块 |
| 3 | 中等工程：创建新的专题内容页面 |
| 4 | 较大工程：建设第三方评测和反向链接 |
| 5 | 长期工程：建立实体信号、提升整体权威度 |

### 优先级计算

```
优先级分 = 影响面评分 x (6 - 修复难度评分)
```

- **P0（紧急）**：优先级分 >= 20 — 立即修复
- **P1（高优先级）**：优先级分 15-19 — 本周内修复
- **P2（中优先级）**：优先级分 10-14 — 两周内修复
- **P3（低优先级）**：优先级分 < 10 — 排入后续计划

### 跨平台权重调整
如果某个丢失查询在多个平台都缺失，优先级上浮一级：
- 单平台缺失：按原始优先级
- 两个平台缺失：优先级 +5 分
- 三个及以上平台缺失：优先级 +10 分
