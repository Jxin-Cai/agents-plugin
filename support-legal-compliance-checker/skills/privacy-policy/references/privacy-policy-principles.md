# 隐私政策原则与参考框架

> 本文档为隐私政策生成技能的参考材料，基于公开法规整理，仅供参考。

---

## 1. 隐私政策必备要素（按法域）

### 通用必备要素

所有法域均要求的基本要素：

1. 数据控制者/处理者的身份和联系方式
2. 收集的个人数据类别
3. 数据处理目的
4. 数据保留期限
5. 用户权利及行使方式
6. 安全措施概述
7. 政策变更通知机制

---

## 2. GDPR 要求的信息条目（Art. 13-14）

### Art. 13 -- 直接收集时应告知：

| 条目 | 说明 | 必要性 |
|------|------|--------|
| 控制者身份和联系方式 | 公司名称、地址、联系邮箱 | 强制 |
| DPO 联系方式 | 如已指定 DPO | 强制（如适用） |
| 处理目的和法律基础 | 每个处理目的对应的 Art. 6 基础 | 强制 |
| 合法利益说明 | 如基于 Art. 6(1)(f) | 强制（如适用） |
| 接收者/接收者类别 | 数据共享对象 | 强制 |
| 跨境传输信息 | 传输目的地、保障措施 | 强制（如适用） |
| 保留期限 | 或确定期限的标准 | 强制 |
| 数据主体权利 | Art. 15-22 的权利清单 | 强制 |
| 撤回同意的权利 | 如基于同意处理 | 强制（如适用） |
| 向监管机构投诉的权利 | 监管机构信息 | 强制 |
| 是否法定/合同要求 | 提供数据的义务性 | 强制 |
| 自动化决策信息 | 逻辑、重要性、后果 | 强制（如适用） |

### Art. 14 -- 非直接收集时额外应告知：

- 个人数据的类别
- 数据来源（包括是否来自公开来源）

## 3. CCPA 要求的信息条目

| 条目 | 条款 | 说明 |
|------|------|------|
| 收集的个人信息类别 | Sec. 1798.100(b) | 过去12个月内收集的类别 |
| 收集目的 | Sec. 1798.100(b) | 每个类别的商业或商业目的 |
| 信息来源类别 | Sec. 1798.110(c)(2) | 个人信息的来源 |
| 出售/共享的信息类别 | Sec. 1798.115(c) | 过去12个月内出售或共享的类别 |
| 第三方类别 | Sec. 1798.115(c) | 接收出售/共享数据的第三方类别 |
| 消费者权利说明 | Sec. 1798.130 | 知情权、删除权、拒绝出售权的说明 |
| 权利行使方式 | Sec. 1798.130 | 至少两种提交请求的方式 |
| 非歧视声明 | Sec. 1798.125 | 不因行使权利而歧视 |
| "Do Not Sell" 链接 | Sec. 1798.135 | 首页显眼位置 |

## 4. PIPL 要求的信息条目

| 条目 | 条款 | 说明 |
|------|------|------|
| 处理者名称和联系方式 | Art. 17(1) | 处理者身份信息 |
| 处理目的和方式 | Art. 17(2) | 明确且具体 |
| 处理的个人信息种类 | Art. 17(3) | 详细列明 |

## 6. 数据保留期设定原则

| 原则 | 说明 | 示例 |
|------|------|------|
| **目的限制** | 保留期限不应超过实现处理目的所需的时间 | 营销同意记录：同意有效期内 + 记录保留5年 |
| **法律要求** | 某些数据有法定最低保留期 | 财务记录：通常7年（税法要求） |
| **诉讼时效** | 考虑潜在法律纠纷的时效期 | 合同记录：合同终止后3-6年 |
| **行业标准** | 参考行业最佳实践 | 医疗记录：成人后至少10年 |
| **最小化原则** | 在满足上述要求后尽早删除或匿名化 | 非活跃账户数据：2-3年后删除 |

### 常见数据类别保留期参考

| 数据类别 | 建议保留期 | 依据 |
|---------|-----------|------|
| 账户信息 | 账户存续期 + 删除后30天 | 业务需要 |
| 交易记录 | 交易完成后7年 | 税法/会计法要求 |
| 客服记录 | 3年 | 投诉处理 + 诉讼时效 |
| 营销偏好 | 同意有效期内 | 同意管理 |
| 日志数据 | 90天-1年 | 安全与故障排查 |
| Cookie 数据 | 最长13个月（CNIL 建议） | 监管指南 |

## 7. 跨境数据传输机制

### GDPR 框架下的合法传输机制（Art. 44-49）

| 机制 | 说明 | 适用场景 |
|------|------|---------|
| **充分性认定** | 欧盟委员会认定目的地国家提供充分保护 | 日本、韩国、英国、加拿大等 |
| **标准合同条款 (SCC)** | 欧盟委员会发布的标准数据保护条款 | 最常用机制，适用于大多数场景 |
| **约束性公司规则 (BCR)** | 跨国企业内部的数据保护规则 | 企业集团内部传输 |
| **行为准则/认证** | 行业行为准则或认证机制 | 特定行业 |
| **明确同意** | 数据主体的明确同意 | 偶尔传输，需告知风险 |

### PIPL 框架下的跨境传输机制（Art. 38）

| 机制 | 适用条件 | 说明 |
|------|---------|------|
| **安全评估** | 关键信息基础设施运营者或大量数据 | 向国家网信部门申报 |
| **个人信息保护认证** | 专业机构认证 | 经认证的处理者 |
| **标准合同** | 非关键信息基础设施运营者 | 网信办发布的标准合同 |

## 8. 合规性验证检查清单

### GDPR 合规性验证

- [ ] Art. 13/14 要求的所有信息条目均已包含
- [ ] 每个处理目的都有明确的法律基础
- [ ] 数据主体的所有权利均已说明
- [ ] 撤回同意的方式已说明（如基于同意）
- [ ] 自动化决策信息已披露（如适用）
- [ ] 跨境传输机制已说明（如适用）
- [ ] DPO 联系方式已提供（如适用）
- [ ] 监管机构投诉权已提及
- [ ] 语言清晰简洁，普通人可理解

### CCPA 合规性验证

- [ ] 过去12个月收集的个人信息类别已列出
- [ ] 信息来源类别已说明
- [ ] 商业/商业目的已列出
- [ ] 出售/共享的信息类别已列出（如适用）
- [ ] 消费者权利已说明
- [ ] 至少两种请求提交方式
- [ ] "Do Not Sell My Personal Information" 链接要求已说明
- [ ] 非歧视声明已包含
- [ ] 过去12个月更新一次

### PIPL 合规性验证

- [ ] Art. 17 要求的所有告知事项均已包含
- [ ] 敏感信息处理的必要性已说明（如适用）
- [ ] 跨境传输的额外告知已完成（如适用）
- [ ] 未成年人（不满14周岁）保护措施已说明
- [ ] 中文版本提供
- [ ] 单独同意的场景已标明
