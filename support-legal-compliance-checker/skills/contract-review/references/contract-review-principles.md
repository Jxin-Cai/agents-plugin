# 合同审查原则与参考框架

> 本文档为合同审查技能的参考材料，基于法律实务经验整理，仅供参考。

---

## 1. 风险关键词分类

### 1.1 高风险关键词

| 关键词 | 风险说明 | 建议处理 |
|--------|---------|---------|
| 无限责任 / unlimited liability | 无上限的赔偿义务 | 要求设置责任上限 |
| 个人担保 / personal guarantee | 法人代表/高管个人承担连带责任 | 坚决拒绝或严格限制范围 |
| 连带责任 / joint and several | 任一方可被要求承担全部责任 | 改为按比例承担 |
| 不可撤销 / irrevocable | 无法单方面解除或终止 | 增加合理退出机制 |
| 放弃权利 / waiver of rights | 预先放弃法定权利 | 删除或限制范围 |
| 自动续约（无终止权） | 合同自动续期且无法终止 | 增加便利终止条款 |
| 排他性（广泛） / exclusive | 限制与其他方合作的权利 | 限缩排他范围和期限 |

### 1.2 中风险关键词

| 关键词 | 风险说明 | 建议处理 |
|--------|---------|---------|
| 赔偿 / indemnify | 一方承担另一方损失的义务 | 确保互惠、设置上限 |
| 竞业限制 / non-compete | 限制竞争活动 | 限制范围、地域、期限 |
| 非招揽 / non-solicitation | 限制招揽对方员工/客户 | 合理期限（通常12个月） |
| IP 转让 / IP assignment | 知识产权归属转移 | 明确范围，保留背景 IP |
| 保密期限 > 5年 | 长期保密义务 | 评估合理性 |
| 不利管辖权 | 争议解决地点不利 | 协商中性管辖地 |

### 1.3 合规相关关键词

| 关键词 | 关注点 | 检查要求 |
|--------|--------|---------|
| 数据处理 / data processing | GDPR Art. 28 合规 | DPA 条款完整性 |
| 个人数据 / personal data | 数据保护义务 | 范围界定、处理限制 |
| 跨境传输 / cross-border | 数据出境合规 | 传输机制合法性 |
| 审计权 / audit right | 合规验证能力 | 确保保留审计权 |
| 安全措施 / security | 数据安全保障 | 措施具体性和充分性 |
| 泄露通知 / breach notification | 事件响应义务 | 通知时限和范围 |

## 2. 合同审查标准流程

```
1. 通读全文 → 了解合同整体结构和主要条款
2. 类型识别 → 确定合同类型和适用审查标准
3. 关键词扫描 → 系统化识别风险关键词
4. 条款逐项分析 → 对关键条款进行深度分析
5. 合规检查 → 数据保护和行业合规条款
6. 风险评级 → 量化各条款和整体风险
7. 修改建议 → 提出具体可行的修改方案
8. 审批建议 → 根据风险等级建议审批流程
```

## 3. 关键条款分析框架

### 3.1 责任限制

**建议标准**：
- 直接损害责任上限 = 过去 **12个月** 已付/应付费用总额
- 间接/后果性损害 → 双方互相排除
- **不应受限的例外**：
  - 故意或重大过失
  - 数据泄露（GDPR 罚款）
  - 知识产权侵权
  - 保密义务违反
  - 赔偿义务

**红线**：
- 无限责任 → 必须修改
- 单方面限制（仅限制对方责任） → 要求互惠
- 责任上限过低（低于3个月费用） → 要求提高

### 3.2 终止权

**建议标准**：
- **便利终止**：任何一方可在 **30天** 书面通知后终止
- **违约终止**：书面通知违约 → **30天** 补救期 → 未补救则终止
- **立即终止事由**：破产、清算、严重违法
- **终止后义务**：
  - 数据返还/删除：终止后 **30天** 内
  - 保密义务存续：终止后 **2-3年**
  - 费用结算：终止后 **30天** 内

**红线**：
- 无终止权或仅对方有终止权 → 必须修改
- 终止需支付高额违约金（超过剩余合同金额） → 协商降低
- 终止后数据不返还 → 必须要求返还/删除

### 3.3 数据保护条款（DPA）

**GDPR Art. 28 要求的 DPA 必备条款**：

| 条款 | 要求 | 条文依据 |
|------|------|---------|
| 处理指令 | 仅按控制者书面指令处理 | Art. 28(3)(a) |
| 保密义务 | 处理人员受保密约束 | Art. 28(3)(b) |
| 安全措施 | 实施 Art. 32 要求的技术和组织措施 | Art. 28(3)(c) |
| 子处理者 | 事先书面授权，同等义务约束 | Art. 28(3)(d) |
| 协助义务 | 协助控制者履行数据主体权利义务 | Art. 28(3)(e) |
| 删除/返还 | 服务结束后删除或返还数据 | Art. 28(3)(g) |
| 审计权 | 允许控制者审计 | Art. 28(3)(h) |
| 泄露通知 | 不当延迟地通知控制者 | Art. 33 |

## 4. 风险评级计算方法

### 评级维度

| 维度 | 权重 | 评分标准 |
|------|------|---------|
| 财务风险 | 30% | 潜在损失金额 vs 合同价值 |
| 合规风险 | 25% | 违反法规的可能性和后果 |
| 运营风险 | 20% | 对业务运营的影响 |
| 法律风险 | 15% | 诉讼/仲裁的可能性 |
| 声誉风险 | 10% | 对品牌/市场形象的影响 |

### 综合评级

| 综合得分 | 风险等级 | 建议操作 |
|---------|---------|---------|
| 0-30 | 低风险 | 标准流程审批 |
| 31-60 | 中风险 | 经理级审批 + 协商修改 |
| 61-100 | 高风险 | 法务部门审查 + 必须修改 |

## 5. 常见修改建议模板

### 5.1 责任限制条款

**原文**（风险示例）：
> 乙方对甲方承担无限赔偿责任。

**建议修改为**：
> 除以下例外情形外，任一方对另一方的累计赔偿总额不超过导致索赔的事件发生前12个月内，根据本协议已支付或应付费用的总额。例外：(a) 故意或重大过失；(b) 违反保密义务；(c) 知识产权侵权赔偿义务。

### 5.2 终止条款

**原文**（风险示例）：
> 本协议自动续约，甲方无权提前终止。

**建议修改为**：
> 任何一方均可在提前30天书面通知另一方后，无因终止本协议。合同期满后自动续约一年，除非任何一方在当前期限届满前至少60天书面通知不续约。

### 5.3 数据处理条款

**建议增加**：
> 乙方应仅根据甲方的书面指令处理个人数据，确保处理人员受保密义务约束，实施适当的技术和组织安全措施，在使用子处理者前获得甲方书面同意，协助甲方响应数据主体权利请求，在服务终止后按甲方指示删除或返还所有个人数据，并允许甲方进行合规审计。

## 6. 审批流程设计

```
┌─────────────┐     ┌──────────────────┐     ┌──────────────────┐
│   低风险     │     │     中风险        │     │     高风险        │
│  (得分 0-30) │     │   (得分 31-60)    │     │   (得分 61-100)   │
└──────┬──────┘     └────────┬─────────┘     └────────┬─────────┘
       │                     │                         │
       ▼                     ▼                         ▼
 标准流程审批          经理级审批               法务部门审查
 (业务负责人)        (部门经理 +               (法务总监 +
                     合规经理)                 外部律师)
       │                     │                         │
       ▼                     ▼                         ▼
  可直接签署          协商修改后签署            必须修改后签署
                    (高风险条款需修改)         (全部风险条款修改)
```

### 审批时效建议

| 风险等级 | 审批时效 | 升级条件 |
|---------|---------|---------|
| 低风险 | 3个工作日 | 超时自动升级 |
| 中风险 | 5个工作日 | 涉及数据合规升级至高风险 |
| 高风险 | 10个工作日 | 涉及重大金额需 CEO 审批 |
