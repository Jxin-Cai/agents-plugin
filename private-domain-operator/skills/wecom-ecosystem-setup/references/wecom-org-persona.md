# 企微组织架构与人设设计

## 团队架构设计

企微私域团队的组织架构应根据业务规模分级设计：

**初创期（好友<1万）**
```
私域负责人（1人）
├── 运营专员（1-2人）：内容+社群+活动
└── 客服（1人）：咨询+售后
```

**成长期（好友1-10万）**
```
私域负责人（1人）
├── 内容组（2-3人）：内容策划+素材制作
├── 运营组（2-3人）：社群运营+活动策划
├── 销售组（2-5人）：1对1成交+客户跟进
└── 数据专员（1人）：数据分析+报表
```

**成熟期（好友>10万）**
```
私域总监（1人）
├── 内容中心（5+人）
├── 社群运营（5+人）
├── 销售团队（10+人）
├── SCRM/技术（2-3人）
├── 数据分析（2-3人）
└── 合规/品控（1-2人）
```

## 员工号人设设计

| 人设类型 | 适用场景 | 头像风格 | 朋友圈风格 |
|---------|---------|---------|-----------|
| 品牌顾问 | 高客单价、专业服务 | 职业照 | 专业知识+案例分享 |
| 福利官 | 促销导向、高频消费 | 品牌IP形象 | 福利预告+限时活动 |
| 专属客服 | 售后服务、客户维护 | 亲和力真人照 | 使用技巧+用户反馈 |
| 创始人IP | 品牌故事、信任背书 | 创始人真人照 | 品牌理念+幕后故事 |
| 专家KOC | 知识付费、咨询类 | 专业形象照 | 行业洞察+干货分享 |

## 员工号管理规范

- 每个员工号好友上限建议控制在 5000 以内（企微上限 2 万，但管理效率在 5000 时最优）
- 朋友圈发布频率：每天 1-3 条，避免刷屏
- 朋友圈内容比例：价值内容 60% + 产品种草 25% + 促销信息 15%
- 名片信息完整：头像+昵称+签名+电话+地址
