# 渠道活码类型与配置

## 活码类型详解

**员工活码（个人码）**
- 支持多个员工轮流接待，自动均分流量
- 可设置添加上限，达到上限自动切换下一个员工
- 适用于：1对1 场景（高客单、需求咨询、售后）

**群活码**
- 支持多个群轮流承接，单群满员自动切换
- 群满员阈值建议设为 180 人（200 人上限留 buffer）
- 适用于：批量引流场景（活动引流、直播引流）

**渠道活码（带参数）**
- 每个渠道生成独立活码，自动追踪来源
- 支持关联自动标签和欢迎语
- 适用于：多渠道引流归因

## 各渠道活码配置指南

**包裹卡**
```yaml
活码类型: 员工活码
承接员工: 福利官人设
欢迎语: "Hi~ 我是{品牌}的专属福利官{名字}，感谢你购买{产品}，给你准备了一份老客专属福利，回复「1」领取 →"
自动标签: [来源:包裹卡, 消费:已购客户]
设计要点: 卡片名片大小(90x54mm)，利益点突出，二维码≥2cm
转化率基准: 3-8%
```

**直播间**
```yaml
活码类型: 群活码
承接群: 直播福利群
欢迎语: "欢迎进入{品牌}直播福利群！直播专属优惠将在群内发放，还有不定期秒杀和抽奖活动"
自动标签: [来源:直播, 偏好:直播购物]
设计要点: 口播+贴片引导，限时限量制造紧迫感
转化率基准: 5-15%
```

**门店**
```yaml
活码类型: 员工活码
承接员工: 对应门店员工
欢迎语: "你好呀~ 我是{门店名}的{名字}，以后有任何问题都可以找我，先送你一张会员专属券 →"
自动标签: [来源:门店, 来源:门店_{门店编号}]
设计要点: 收银台立牌/桌贴，结合买单优惠引导扫码
转化率基准: 15-30%
```

**短信召回**
```yaml
活码类型: 员工活码
承接员工: 专属客服
欢迎语: "终于等到你回来啦 {昵称}~ 好久不见，给你准备了一份回归礼，回复「领取」即可获得 →"
自动标签: [来源:短信召回, 生命周期:沉睡回流]
设计要点: 短信内嵌短链+活码落地页，强调"专属""老客"身份认同
转化率基准: 1-3%
```
