# 客户标签体系设计方法论

标签体系是私域精细化运营的核心基础设施。设计不好的标签体系比没有标签更糟糕——它会产生错误的运营决策。

## 四维标签框架

### 维度一：来源标签（Where）

| 一级标签 | 二级标签示例 | 打标方式 |
|---------|------------|---------|
| 渠道来源 | 包裹卡/直播/门店/广告/自然/老带新 | 渠道活码自动 |
| 首次触点 | 具体活动名/页面名/员工号 | 渠道活码自动 |
| 首次时间 | 加好友日期 | 系统自动 |

### 维度二：消费标签（What）

| 一级标签 | 二级标签示例 | 打标方式 |
|---------|------------|---------|
| 消费层级 | 未购/首购/复购/高价值 | 订单数据同步 |
| 客单价区间 | 0/1-99/100-299/300+ | 订单数据同步 |
| 品类偏好 | 具体品类名（如护肤/彩妆/身体护理） | 订单数据同步 |
| RFM 评分 | R(最近)/F(频率)/M(金额)组合 | 定期计算更新 |

### 维度三：生命周期标签（When）

| 一级标签 | 定义 | 打标方式 |
|---------|------|---------|
| 新客 | 加好友 0-7 天 | 时间自动计算 |
| 成长期 | 加好友 7-30 天 | 时间自动计算 |
| 成熟期 | 加好友 30-90 天且有购买 | 时间+订单联合判断 |
| 沉睡期 | 90 天内无互动无购买 | 行为数据自动检测 |
| 流失 | 删除好友/180天无任何行为 | 系统检测 |

### 维度四：偏好标签（How）

| 一级标签 | 二级标签示例 | 打标方式 |
|---------|------------|---------|
| 内容偏好 | 种草型/促销型/知识型/互动型 | 点击行为分析 |
| 互动水平 | 高互动/中互动/低互动/潜水 | 消息回复率计算 |
| 活跃时段 | 早间(7-9)/午间(12-14)/晚间(20-22) | 互动时间统计 |
| 社群活跃 | 核心成员/活跃成员/潜水成员/僵尸 | 群内行为统计 |

## 标签管理原则

1. **少即是多**：初期标签不超过 30 个，避免标签泛滥导致无法管理
2. **自动优先**：能自动打标的绝不手动，手动标签误差大且不可持续
3. **定期清洗**：每月检查标签覆盖率和准确率，清理无效标签
4. **权限分级**：核心标签（如消费层级）只允许系统打标，不允许手动修改
