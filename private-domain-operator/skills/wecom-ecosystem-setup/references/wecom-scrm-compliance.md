# SCRM 选型与合规配置

## SCRM 工具对比

| 工具 | 定位 | 核心功能 | 适合场景 | 价格 |
|------|------|---------|---------|------|
| 微伴助手 | 轻量全功能 | 渠道活码、自动标签、群SOP、数据看板 | 初创期(<3万好友)、预算有限 | 免费-1万/年 |
| 尘锋 SCRM | 销售驱动 | 线索分配、销售跟进、会话质检、业绩报表 | 有销售团队(3-30万好友) | 1-5万/年 |
| 微盛 | 社群管理 | 社群雷达、群SOP、群活码、群数据分析 | 社群密集型(>50群) | 5k-3万/年 |
| 句子互动 | 技术驱动 | RPA自动化、智能路由、API对接、自定义工作流 | 有技术团队、需深度定制 | 定制报价 |

### 选型决策路径

- 预算<1万/年 → 微伴助手（免费版或基础版）
- 核心需求偏销售跟进 → 尘锋 SCRM
- 核心需求偏社群运营 → 微盛
- 两者兼需+有技术团队 → 句子互动
- 两者兼需+无技术团队 → 尘锋（综合能力更均衡）

## 会话存档合规要求

**法律依据：** PIPL（2021.11.1施行）、《网络安全法》、企微官方会话存档接口规范

**合规要点：**
1. **告知义务**：必须明确告知用户会话存档并获得同意
2. **同意获取**：内部员工在劳动合同中明确；外部客户加好友时弹出存档提醒
3. **数据安全**：加密存储、访问权限严格控制、保存期限不超过必要期限
4. **使用限制**：仅合规审计和质量管理，员工离职后及时处理相关数据

**配置步骤：**
1. 管理员在企微后台开通会话存档功能
2. 配置存档范围（哪些员工的会话需要存档）
3. 设置外部联系人提醒文案（合规告知）
4. 对接 SCRM 系统的会话存档 API
5. 配置数据加密密钥和访问权限

## 离职继承与在职转移

### 离职继承
- 在企微后台设置离职继承规则，指定继承人（优先同部门同角色员工）
- 自定义继承通知文案（不用默认文案）：新员工自我介绍→交接原因→权益保留承诺
- 继承后 24 小时内由新员工主动打招呼

### 在职转移
- 需原员工和新员工双方确认，客户收到系统通知
- 聊天记录不丢失（会话存档需重新授权），标签和备注完整转移

### 风险防范
- 员工离职前批量导出 → 设置数据导出权限
- 员工带走客户 → 合同约定竞业禁止+客户归属权
- 继承后客户流失 → 提前过渡，密切关注删除率
