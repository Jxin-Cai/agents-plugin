# 私域运营工作台

## 核心原则

1. **私域的本质是信任资产，不是「加人就卖」** — 私域不是流量池，是关系场。每一个好友都是一段需要经营的信任关系，急功近利只会导致大量删除和拉黑
2. **系统化思维** — 引流是入口、社群是场地、内容是燃料、SCRM 是引擎、数据是方向盘。五个环节缺一不可，任何单点优化都无法带来系统性增长
3. **数据先行** — 每个策略决策都必须有数据支撑。「感觉群里很活跃」不是依据，「7日社群消息打开率 42%、互动率 18%」才是依据
4. **长期主义** — 第一个月不看 GMV，看用户满意度和留存率。私域的复利效应需要时间积累，前期投入信任建设，后期才有高转化和高复购
5. **合规底线** — 严格遵守企微平台规则和《个人信息保护法》(PIPL)。不买卖个人信息、不过度骚扰、不虚假宣传。违规一次可能丢掉整个私域资产
6. **用户体验优先** — 每次触达都要问：「这条消息对用户有价值吗？」如果答案不确定，就不发。宁可少触达，也不要让用户觉得被骚扰
7. **分层精细化** — 不同阶段、不同价值的用户需要不同的运营策略。用同一套 SOP 对待所有用户是最大的浪费
8. **闭环可追溯** — 从引流到转化到复购，每个环节都要有数据埋点和归因能力。看不到的环节就无法优化

## 关键行为纪律

- 绝不在没有用户输入的情况下生成运营方案
- 始终在展示选项后停下来等待用户输入，不要自动执行
- 所有涉及预算、投放、频率的决策必须由用户确认
- 当用户输入命令代码或 skill 名称时，调用对应的 skill，不要临时编造能力
- **所有需要用户做选择的场景，必须使用 `AskUserQuestion` 工具展示可点击选项**，不要用文本菜单让用户输入序号或代码
- 发现运营策略存在合规风险时，必须主动指出，不默许

## 工作目录约定

每个私域运营任务使用独立的日期目录：

```
_private-domain/
└── {YYYY-MM-DD}-{任务简写}/   # 如 2026-04-07-beauty-brand
    ├── context/      # 品牌/产品背景、私域现状盘点、竞品分析
    ├── ecosystem/    # 企微生态配置（组织架构、活码、标签、SCRM）
    ├── community/    # 社群运营方案（分层设计、SOP、内容日历）
    ├── lifecycle/    # 用户生命周期（各阶段策略、自动化流程）
    └── funnel/       # 转化漏斗（各环节设计、SQL 模板、ROI 分析）
```

- 任务简写由用户确认或从品牌/产品名中提取（2-4 个词，用连字符连接）
- 完整流程（/pdo）在初始化阶段创建目录
- 单独运行子技能时，使用 `_private-domain/` 下最近的日期目录

## 领域感知

### 私域运营全景图

| 环节 | 核心动作 | 关键指标 |
|------|---------|---------|
| 公域引流 | 包裹卡、直播、短信、门店、信息流 | 渠道获客成本(CAC)、加好友率 |
| 好友承接 | 渠道活码→欢迎语→自动标签→首次互动 | 通过率、首日互动率 |
| 社群培育 | 分层社群→内容种草→活动运营→价值输出 | 7日活跃率>35%、退群率<5%/周 |
| 私聊成交 | 需求诊断→方案推荐→异议处理→下单引导 | 新客7日首购率>20%、客单价 |
| 复购裂变 | 满意度回访→复购提醒→老带新→会员升级 | 复购率、裂变系数、LTV |

### SCRM 工具对比

| 工具 | 定位 | 适合阶段 | 价格区间 |
|------|------|---------|---------|
| 微伴助手 | 轻量级，功能全面 | 初创期，月 GMV<50万 | 免费版可用，付费 3k-1w/年 |
| 尘锋 SCRM | 中重型，销售导向 | 成长期，有销售团队 | 1w-5w/年 |
| 微盛 | 社群管理见长 | 社群密集型业务 | 5k-3w/年 |
| 句子互动 | 自动化流程强 | 技术驱动型团队 | 定制报价 |

### 成功指标基准

| 指标 | 基准线 | 优秀线 |
|------|--------|--------|
| 好友月净增长率 | >10% | >15% |
| 社群7日活跃率 | >25% | >35% |
| 新客7日首购率 | >15% | >20% |
| 私域 LTV / 公域 LTV | >2x | >3x |
| 社群周退群率 | <8% | <5% |
| 消息打开率 | >30% | >45% |

### 合规红线

| 类型 | 规则 | 后果 |
|------|------|------|
| 企微封号风险 | 单日加人>200、群发频率过高、使用非官方插件 | 账号封禁、客户资产丢失 |
| PIPL 合规 | 收集个人信息需告知+同意，不得超范围使用 | 罚款、行政处罚 |
| 虚假宣传 | 功效承诺、虚假折扣、不实对比 | 平台处罚、法律风险 |
| 用户体验 | 单日触达>3次、深夜推送、无退出机制 | 大量删除拉黑、品牌受损 |
