# 新成员 72 小时 SOP

## 为什么是72小时？

- 前 24 小时内不互动的用户，60% 会在一周内退群
- 前 72 小时产生首次互动的用户，30 天留存率是未互动用户的 3 倍
- 前 72 小时完成首购的用户，LTV 是未首购用户的 2.5 倍

## 详细执行流程

**入群即刻（0分钟）**
```
触发: 新人入群
动作:
  1. 自动发送欢迎语（SCRM自动触发）
  2. @新人+群规简介
  3. 引导自我介绍（提供模板降低门槛）
欢迎语模板:
  "欢迎 @新人昵称 加入{品牌}家族！
   群里每天都有福利和干货分享：
   每晚8点 红包/抽奖 | 每天更新 {品类}知识 | 不定期 专属秒杀
   先来个自我介绍吧～ 我叫___，来自___，最喜欢的{品类}是___"
```

**入群 1 小时内**
```
触发: 新人入群1小时
动作:
  1. 管理员/群主@新人发起破冰话题
  2. 引导老成员互动欢迎
  3. 发送群精华内容合集链接
破冰话题:
  "@新人昵称 看到你喜欢{XX}，我们群里好多人也是！
   大家来聊聊最近在用什么{产品类型}？"
```

**入群 6 小时内**
```
触发: 入群6小时
动作:
  1. 1对1私聊（品牌顾问/客服号）
  2. 了解基本需求
  3. 推荐适合的产品/内容
私聊模板:
  "Hi {昵称}，欢迎加入我们～
   方便问一下你是通过什么渠道知道我们的呀？
   最近有什么{品类}方面的需求吗？我可以给你推荐最适合你的产品"
```

**第2天**
```
触发: 入群第2天上午10点
动作:
  1. 1对1私聊跟进（如果昨天没回复）
  2. 推送新人专属内容（入门指南/选购攻略）
  3. 群内@新人参与当日话题
内容推送:
  "给你准备了一份{品类}入门指南，看完就知道怎么选啦～
   [链接/图片] 有问题随时问我"
```

**第3天**
```
触发: 入群第3天
动作:
  1. 推送新人专属福利（限时24小时）
  2. 群内邀请参与互动活动
  3. 如果已首购→感谢+使用引导
  4. 如果未首购→再次推荐+降低门槛
福利推送:
  "专属新人福利来啦！限时24小时，{具体福利内容}
   仅限新入群3天内的小伙伴可以领 → 点击领取"
```
