# 社群分层体系详解

## 分层的底层逻辑

社群分层不是为了「看起来高级」，而是解决一个核心矛盾：**不同价值的用户需要不同密度的运营**。

- 低价值用户需要低成本的批量化运营（群运营）
- 高价值用户需要高投入的个性化服务（1对1+小群）
- 如果用同一套方案运营所有人，要么成本撑不住，要么高价值用户被怠慢

## 各层级详细设计

**L1 引流群（快闪群/主题群）**

| 维度 | 说明 |
|------|------|
| 定位 | 流量入口，快速承接+初步筛选 |
| 人数 | 150-200人/群 |
| 生命周期 | 3-7天（快闪模式）或持续运营 |
| 运营密度 | 低：每天1-2条内容+1个活动 |
| 核心动作 | 发福利→建立信任→筛选活跃用户→引导进入L2 |
| 退出机制 | 快闪群到期解散 / 不活跃自然流失 |

快闪群运营SOP（7天生命周期）：
```
Day 1: 拉群+群规+自我介绍+首日福利（制造热闹感）
Day 2: 产品种草+互动话题（建立价值感）
Day 3: 限时秒杀/拼团（制造紧迫感+首次转化）
Day 4: 用户反馈展示+答疑（建立信任感）
Day 5: 深度内容分享（提升专业感）
Day 6: 会员日/特别福利（提升参与感）
Day 7: 总结+邀请加入长期群（筛选+毕业）
```

**L2 福利群（日常运营群）**

| 维度 | 说明 |
|------|------|
| 定位 | 日常运营主阵地，内容种草+活动转化 |
| 人数 | 100-180人/群（不要太满，留出互动空间） |
| 准入 | L1活跃用户 / 包裹卡等渠道直接引流 |
| 运营密度 | 中：每天3-5条内容+定期活动 |
| 核心动作 | 内容种草→互动活跃→促销转化→筛选VIP |
| 退出机制 | 连续30天零互动移出 |

**L3 VIP群（高价值群）**

| 维度 | 说明 |
|------|------|
| 定位 | 高价值客户专属服务，提升忠诚度和LTV |
| 人数 | 50-100人/群 |
| 准入 | 累计消费>X元 / 复购>N次 / 推荐>M人 |
| 运营密度 | 高：每天有专属内容+1对1关怀 |
| 核心动作 | 专属权益→优先体验→交叉销售→口碑传播 |
| 退出机制 | 消费降级则降回L2（温和告知） |

VIP群专属权益：新品优先体验、专属折扣（比大促价更低）、生日礼包、1对1专属客服、线下活动优先名额、退换货绿色通道

**L4 超级用户群（KOC群）**

| 维度 | 说明 |
|------|------|
| 定位 | KOC培育+内容共创+裂变引擎 |
| 人数 | 20-30人/群 |
| 准入 | VIP群中高互动+自发产出内容+推荐转化>N人 |
| 运营密度 | 极高：几乎每天有个性化互动 |
| 核心动作 | 共创内容→体验官→分销佣金→裂变激励 |
| 退出机制 | 3个月无内容产出降回VIP |
