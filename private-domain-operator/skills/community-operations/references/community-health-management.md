# 社群健康管理

## 羊毛党防范

### 识别特征

| 信号 | 权重 | 说明 |
|------|------|------|
| 多次使用不同手机号注册 | 高 | 设备指纹+手机号关联检测 |
| 只参与优惠活动不互动 | 中 | 活动参与率高但日常互动为零 |
| 批量转售行为 | 高 | 同一地址多次下单+闲鱼检测 |
| 薅完即退群 | 高 | 活动结束后24小时内退群 |
| 异常时段批量操作 | 高 | 凌晨批量加群/抢券 |

### 防范措施

**事前：** 新人入群需验证问题（过滤机器人）；秒杀/抽奖限制同一手机号/设备/地址限购；优惠券设使用门槛；新人福利需先完成互动任务

**事中：** 实时监控异常订单（同地址多单、异常客单价）；社群内监控批量拉人、广告、频繁链接；SCRM设置预警规则自动标记

**事后：** 羊毛党订单取消+拉黑；群内推广警告→禁言→移出；每月检查清理异常账号

## 社群活跃率管理

### 定义与基准

**活跃率 = 7天内有互动行为的成员数 / 群总人数**

互动行为：发消息、回复、点赞、参与投票、参与接龙、领取红包（不含已读）

| 活跃率 | 健康度 | 对应策略 |
|--------|--------|---------|
| >40% | 优秀 | 保持节奏，培育KOC |
| 25-40% | 健康 | 增加互动活动频率 |
| 15-25% | 亚健康 | 调整内容策略+增加福利 |
| <15% | 危险 | 大刀阔斧改革或考虑解散重建 |

### 提升活跃率的10个方法

1. **红包开场法** — 发内容前先发小红包（0.5-1元/个），用红包吸引注意力
2. **话题投票法** — 二选一投票降低互动门槛，比"说说你的想法"容易10倍
3. **接龙裂变法** — 群接龙+限量福利，前N名有奖，制造参与感和紧迫感
4. **UGC征集法** — 晒单有奖/使用心得征集，用户内容比品牌内容更有信服力
5. **人设互动法** — 品牌人设主动@用户聊天、回复评论、私聊破冰，让群有「人味」
6. **固定栏目法** — 每天固定时间固定栏目，培养用户习惯
7. **悬念预告法** — 提前预告次日活动/福利，制造期待感
8. **游戏化积分** — 互动积分→兑换福利，让日常互动有累积价值
9. **社群小KOL** — 培养群内活跃用户成为「气氛组」，带动他人
10. **定期洗群** — 移出长期潜水僵尸用户，释放名额提升活跃率

### 活跃率下降常见原因

| 原因 | 表现 | 解决方案 |
|------|------|---------|
| 内容同质化 | 每天都差不多 | 增加内容多样性，引入UGC |
| 广告感太强 | 促销信息过多 | 调整比例，增加价值内容 |
| 缺少互动设计 | 只有单向输出 | 增加话题、投票、游戏 |
| 群规过严 | 用户不敢说话 | 适度放松，鼓励轻松聊天 |
| 管理员缺位 | 没人回复没人管 | 确保每天有人值班互动 |
| 群太大 | 消息焦虑 | 控制人数或分群 |
