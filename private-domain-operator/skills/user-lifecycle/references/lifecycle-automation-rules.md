# 自动化触达规则

## 触达黄金原则

1. **有理由再触达** — 每次必须有明确理由（时间节点/行为触发/价值传递），不为触达而触达
2. **频率控制** — 同一用户每天最多 2 次（私聊1+社群/朋友圈1），一周不超过 5 次私聊
3. **时段选择** — 优先级：20:00-21:30 > 12:00-13:00 > 10:00-11:00，避免早于8:00和晚于22:00
4. **内容递进** — 随关系深度递进：关怀→价值→引导→促成，不要跳跃

## 行为触发式规则

## 内容模板设计原则

| 场景 | 语气 | 长度 | 关键要素 |
|------|------|------|---------|
| 欢迎语 | 热情亲切 | 50-100字 | 自我介绍+价值承诺+行动引导 |
| 关怀跟进 | 真诚关心 | 30-60字 | 提问式开头+不推销 |
| 产品推荐 | 专业种草 | 80-150字 | 场景痛点+产品方案+社会证明 |
| 优惠触发 | 紧迫直接 | 40-80字 | 专属感+限时限量+行动按钮 |
| 唤醒话术 | 温暖+稀缺 | 60-100字 | 关怀开头+专属福利+低门槛 |
