# 用户访谈原则

---

## 1. 漏斗式提问结构（Funnel Approach）

| 层级 | 目标 | 示例 |
|------|------|------|
| 开放探索层 | 让参与者进入叙事模式 | "跟我说说你平时怎么 [做某件事]" |
| 聚焦深挖层 | 把模糊描述转化为具体细节 | "你刚才提到了 X，能多说一些吗？" |
| 具体验证层 | 确认理解准确 | "如果我理解对的话，你的意思是 X？" |

**检验方法**：如果第一个问题就很具体，说明跳过了上层，需返回加宽入口问题。

---

## 2. 开放式问题设计

### 问题类型库

| 类型 | 模板 | 适用场景 |
|------|------|---------|
| 行为回忆 | "上一次你 [做某事] 是什么时候？带我走一遍" | 了解真实行为 |
| 对比探索 | "之前用的方案和现在比起来怎么样？" | 理解迁移动因 |
| 困难发现 | "在 [某场景] 中，最让你头疼的是什么？" | 定位痛点 |
| 期望探索 | "如果能改变 [某件事]，你会改变什么？" | 发现未满足需求 |
| 情境重现 | "带我回到那个场景——当时你在哪里？在做什么？" | 还原使用上下文 |
| 关键事件 | "说一次让你印象特别深的 [好/坏] 经历？" | 关键事件法（CIT） |
| JTBD 触发 | "第一次决定使用 [产品] 时，是什么情况触发的？" | 发现雇佣动因 |

### 必须避免的问题

| 错误类型 | 示例 | 修正 |
|---------|------|------|
| 引导性 | "你不觉得这个设计很复杂吗？" | "你对这个设计有什么感受？" |
| 封闭式 | "你喜欢这个功能吗？" | "你平时怎么使用这个功能？" |
| 双筒式 | "它好用吗？用的时候开心吗？" | 拆成两个独立问题 |
| 假设性 | "如果有 X 功能你会用吗？" | "你现在怎么解决 X 问题？" |
| 术语化 | "你对 UI 的信息架构怎么看？" | "你找某个功能的时候容易吗？" |

## 3. 追问技巧（Probing Techniques）

| 类型 | 用法 | 时机 |
|------|------|------|
| 回声追问 | 重复关键词："你说'很困难'——具体难在哪？" | 参与者用了抽象描述 |
| 沉默追问 | 保持沉默 5 秒，用眼神和点头鼓励继续 | 参与者停顿思考 |
| 深挖追问 | "能多说一些吗？"、"然后呢？" | 参与者跳过了细节 |
| 澄清追问 | "你说的 X 具体是指什么？举个例子？" | 表述模糊 |
| 对比追问 | "这和之前的体验有什么不同？" | 参与者提到了意外行为 |

---

## 4. 认知偏误规避

| 偏误 | 对策 |
|------|------|
| 社会期望偏差 | 问行为而非态度；用"上一次"代替"通常" |
| 确认偏误 | 主动寻找反例；让另一人独立分析 |
| 锚定效应 | 延迟形成结论；多人独立编码 |
| 回忆偏差 | 聚焦最近一次经历；请参与者边操作边说 |
| 峰终定律 | 引导回忆完整流程，不只问"印象最深的" |
| 霍桑效应 | 暖场充分、语气自然、避免评判感 |

---

## 5. 知情同意与伦理

- 必须包含：研究目的简述、参与者权利（随时退出）、数据用途与匿名处理、录音权限、预计时长、报酬说明
- 伦理红线：不施压、不在不适时追问、不欺骗、未成年需监护人同意、敏感话题提前预警

---

## 6. 数据质量控制

- **访谈前**：至少 1 次 Pilot Test；审查引导性/封闭式/双筒式问题；检查录音设备
- **访谈中**：实时标记关键发现和情绪信号；记录原话（Verbatim）；观察非语言线索
- **访谈后**：24 小时内完成备忘录；标记需后续验证的发现；更新研究假设
