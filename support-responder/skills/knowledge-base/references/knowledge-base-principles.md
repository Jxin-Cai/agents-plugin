# 知识库建设原则与参考

## 文章五层递进结构

1. **问题描述** — 让用户确认"这就是我遇到的问题"
2. **常见原因** — 按概率从高到低列出
3. **分步解决** — 引导用户一步步执行
4. **高级排错** — 覆盖"上面方法不管用"的情况
5. **联系支持** — 兜底引导

## 写作原则

| 原则 | 正确示范 | 错误示范 |
|------|----------|----------|
| 标题即问题 | 无法登录账号怎么办？ | Authentication Error Resolution |
| 一篇一问 | 每篇只解决一个问题 | 所有登录问题合集 |
| 步骤可执行 | 点击右上角"设置"图标 | 进入设置页面 |
| 截图必备 | 关键步骤附截图/GIF | 纯文字描述操作 |
| 时效标注 | 适用 v3.2+，更新于 2026-04 | 无版本和日期 |

## 分类体系设计

- **互斥**：一个问题只属于一个分类
- **穷尽**：所有问题都能找到归属
- **均衡**：每个分类 5-15 篇（太少合并，太多拆分）
- **扁平**：最多三级，首选两级

导航结构：搜索栏（最显眼） → 热门 Top 10 → 按分类浏览（图标+名称+数量） → 最近更新

## 搜索优化

| 策略 | 说明 |
|------|------|
| 同义词映射 | 登录/登陆/sign in、密码/口令/password、退款/退费/refund |
| 标签维度 | 问题类型、产品模块、用户类型、难度等级、平台 |
| 无结果优化 | 拼写建议 → 相关分类 → 热门文章 → 联系支持 |

## 文章效果评估

| 指标 | 计算方法 | 健康值 |
|------|----------|--------|
| 有用投票率 | 点"有用" / 总阅读量 | > 70% |
| 跳出率 | 阅读 < 10s 的比例 | < 30% |
| 搜索→阅读转化 | 搜索后点击 / 搜索次数 | > 50% |
| 阅读后工单率 | 阅读后仍创建工单 / 总阅读量 | < 15% |
| 覆盖率 | 有对应文章的工单类型 / 总类型 | > 90% |

健康度 = 有用投票率×0.3 + (1-跳出率)×0.2 + (1-阅读后工单率)×0.3 + 时效性×0.2

时效性：更新<30天=1.0 / 30-90天=0.7 / >90天=0.3

## 持续改进

月度节奏：数据收集(1日) → 问题识别(5日前) → 改进行动(10日前) → 效果追踪(下月)

工单-知识库联动：工单关闭 → 有文章则检查更新需求 → 无文章且月频>5次则创建
