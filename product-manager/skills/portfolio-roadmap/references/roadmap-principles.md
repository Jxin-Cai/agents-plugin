# 产品组合与路线图原则

## 核心目标

路线图工作的核心不是列清单，而是解释：
- 为什么先做这个
- 为什么现在做
- 为什么有些需求这个周期不做

## 关键原则

1. **目标先于条目** — 先明确时间窗和目标，再谈排期
2. **机会池先于路线图** — 先把机会整理清楚，再排时段
3. **主题高于零散需求** — 尽量按主题组织，不按随机需求堆砌
4. **量化优先级** — RICE / WSJF / MoSCoW 至少选一种
5. **明确不做什么** — 不做项和后置项一样重要
6. **区分承诺与探索** — 路线图里要明确哪些是探索，哪些是交付承诺
7. **风险显式化** — 对关键依赖、治理要求、容量约束要写清楚

## 最低产出要求

- 机会池
- 优先级依据
- 路线图视图
- 本周期不做项
- 风险与依赖说明
