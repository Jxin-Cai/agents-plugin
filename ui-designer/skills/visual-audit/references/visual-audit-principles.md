# 视觉审计原则

---

## 1. Nielsen 启发式评估

### 流程
规划（明确范围+准备模板）-> 独立评估（逐项检查）-> 汇总（去重+排序）-> 改进（按优先级修复+复验）

### 严重程度量表
| 等级 | 含义 | 行动 |
|------|------|------|
| 0 | 非问题 | 无需行动 |
| 1 | 装饰性 | 低优先级 |
| 2 | 轻微可用性问题 | 下一迭代修复 |
| 3 | 严重可用性问题 | 高优先级修复 |
| 4 | 可用性灾难 | 上线前必须修复 |

### 十大启发式速查
| # | 启发式 | 关键检查点 |
|---|--------|-----------|
| H1 | 系统状态可见性 | 加载指示器、操作成功/失败反馈、当前位置标识、长操作进度提示 |
| H2 | 系统与真实世界匹配 | 用户语言而非技术术语、图标隐喻符合认知、信息排列符合心智模型、本地化格式 |
| H3 | 用户控制与自由 | 返回/取消/关闭操作、撤销支持、多步流程可回退、紧急出口 |
| H4 | 一致性与标准 | 同类操作跨页一致、遵循平台惯例、术语全站统一、视觉样式一致 |
| H5 | 错误预防 | 危险操作二次确认、输入格式约束、不可用操作禁用/隐藏、提交前客户端校验 |
| H6 | 识别优于回忆 | 选项可见、上下文提示(Placeholder/Tooltip)、历史记录、搜索自动补全 |
| H7 | 灵活性与效率 | 快捷方式、批量操作、自定义界面/流程、键盘快捷键 |
| H8 | 审美与极简设计 | 每个元素有存在必要、信息密度适当、视觉焦点清晰、装饰不干扰内容 |
| H9 | 错误恢复 | 自然语言非错误码、明确说明原因、提供修复建议、靠近出错位置 |
| H10 | 帮助与文档 | 新用户引导(Onboarding)、空状态操作引导、内嵌帮助提示、可搜索文档 |

## 2. Gestalt 视觉原则

| 原则 | 正确应用 | 常见问题 | 检查方法 |
|------|----------|----------|----------|
| 接近性 | 标签紧贴输入框(4-8px)，组间留白(16-24px) | 标签距上下输入框等距致归属模糊 | 遮住标签，凭间距能否判断归属？ |
| 相似性 | 主操作按钮统一样式，可点击链接统一颜色 | 不可点击元素像按钮；同类按钮无法区分 | 纯视觉能否区分可交互/不可交互？ |
| 闭合性 | 用间距和背景色暗示分组，不依赖完整边框 | 过度使用边框和分割线 | 去掉所有线条，仅靠间距能否维持分组？ |
| 连续性 | 列表对齐、时间线连贯、进度条左到右 | 布局打断阅读流，重要信息在视线外 | 追踪 F/Z 型阅读路径，关键信息在路径上？ |
| 图底关系 | 弹窗有遮罩层，卡片有轻微阴影 | 弹窗与背景层次不清，多层叠加混乱 | 能否一眼判断当前焦点区域？ |
| 共同命运 | 展开时子内容同步出现，拖拽时关联元素同步 | 动画不一致致关联元素看起来独立 | 状态变化时关联元素是否同步？ |
| 对称性 | 对称布局传达平衡，打破对称引导注意力 | 无意不对称让布局显得草率 | 不对称是设计决策还是疏忽？ |

## 3. 视觉层次分析

### 快速测试
- **斜视测试**：半眯眼看——能否识别最重要元素？分组是否清晰？视觉重心位置对不对？
- **5 秒测试**：快速扫视——能否说出页面用途？能否找到主要操作入口？能否识别主要内容区？

### 层次工具
| 工具 | 强度 | 适用 |
|------|------|------|
| 字号差异 | 强 | 标题 vs 正文 |
| 颜色对比 | 强 | CTA vs 普通按钮 |
| 字重差异 | 中 | 重要 vs 辅助信息 |
| 间距留白 | 中 | 内容分组 |
| 位置 | 中 | 核心内容在视觉焦点区 |
| 透明度/灰度 | 弱 | 弱化次要信息 |

## 4. 无障碍基线（WCAG 2.1 AA）

| 维度 | 标准 |
|------|------|
| 正文对比度 | >= 4.5:1（<18pt）；大字 >= 3:1（>=18pt 或 14pt 粗体） |
| 非文本 UI 元素 | 对比度 >= 3:1（按钮边框、表单控件） |
| 颜色载体 | 颜色不是唯一信息手段（同时用颜色+图标+文字） |
| 触摸目标 | 最小 44x44px（WCAG 2.5.5） |
| 焦点指示器 | 键盘导航时清晰可见，顺序符合阅读顺序 |
| 悬停内容 | 可关闭、可悬停、可持久（WCAG 1.4.13） |
| 文本缩放 | 放大至 200% 不丢失内容或功能 |
| 排版 | 行高 >= 1.5x 字号，段间距 >= 2x 字号，不使用纯图片文本 |
