# 时间线规划原则

基于 PMBOK 第七版规划绩效域、关键路径法（CPM）和工作分解结构（WBS）方法论。

---

## 1. 工作分解结构（WBS）

### 核心原则

| 原则 | 说明 |
|------|------|
| 100% 规则 | 子项之和 = 父项全部范围，不多不少，每层级适用 |
| 粒度标准 | 工作包 2-10 人天，可分配单人/小组，可估算可追踪 |
| 分解方法 | 按阶段/按交付物/按功能，同一层级分解标准一致 |

### WBS 字典（每个工作包）

编号和名称、范围描述、交付物、验收标准、负责人、前置依赖

---

## 2. 关键路径法（CPM）

### 正向推算与逆向推算

- **ES（最早开始）** = 所有前置任务中最大的 EF
- **EF（最早完成）** = ES + 工期
- **LF（最晚完成）** = 所有后续任务中最小的 LS
- **LS（最晚开始）** = LF - 工期
- **总浮动** = LS - ES，浮动 = 0 即关键路径

### 依赖关系类型

| 类型 | 含义 | 频率 | 示例 |
|------|------|------|------|
| FS | A 完成后 B 开始 | ~90% | 设计完成 -> 开发开始 |
| SS | A 开始后 B 开始 | 较常见 | 编码开始 -> 代码评审开始 |
| FF | A 完成后 B 完成 | 偶尔 | 测试完成 -> 修复完成 |
| SF | A 开始后 B 完成 | 极少 | 新系统上线 -> 旧系统退役 |

**提前量（Lead）**：后续任务提前开始（负延迟）。**延迟量（Lag）**：强制等待缓冲。

---

## 3. 工期估算技术

### 三点估算法（PERT）——首选方法

```
加权估算 TE = (O + 4M + P) / 6    标准差 σ = (P - O) / 6
O=乐观  M=最可能  P=悲观
68% 在 TE±1σ | 95% 在 TE±2σ | 99.7% 在 TE±3σ
```

### 其他方法

| 方法 | 适用场景 | 准确度 |
|------|---------|--------|
| 类比估算 | 有类似项目历史 | 中等 |
| 参数估算 | 有效率参数 | 较高 |
| 自下而上 | WBS 已分解 | 最高 |

### 常见估算偏差

- 乐观偏差（低估 20-30%）-> 修正：三点估算
- 帕金森定律 -> 修正：明确验收标准
- 学习曲线 -> 修正：前几迭代加 30-50% 缓冲
- 多任务切换（成本 20-40%）-> 修正：减少并行

---

## 4. 缓冲管理（关键链法）

| 缓冲类型 | 位置 | 大小 | 作用 |
|---------|------|------|------|
| 项目缓冲 | 关键路径末尾 | 关键路径总工期 15-25% | 保护截止日期 |
| 汇入缓冲 | 非关键路径汇入关键路径前 | 该路径总工期 25-50% | 防止非关键延迟传导 |
| 资源缓冲 | 关键路径资源变更节点前 | 预警机制 | 确保关键资源到位 |

### 缓冲健康度

- 绿色：消耗率 < 完成率 x 1/3
- 黄色：消耗率在 1/3 到 2/3 之间
- 红色：消耗率 > 完成率 x 2/3

---

## 5. 里程碑与甘特图

里程碑类型：阶段（标记阶段完成）、交付（关键交付物）、决策（Go/No-Go）、外部（外部依赖到位）。间隔不超过 2 周，每个有明确交付物和验收标准，名称用完成态描述。

甘特图文本规范：横轴时间、纵轴按 WBS 编号排列。关键路径 ★、里程碑 ◆、超前 ▲、滞后 ▼。至少每周更新，关键路径每日追踪，偏差 > 10% 触发预警。
