# 情感分析原则

本文档定义了情感分析阶段必须遵循的原则。用这些原则确保情感判断准确、分析维度完整、结论可追溯。

---

## 1. 多维情感分类

情感不是简单的正/负/中三分法。完整的情感分析必须覆盖多个维度：

### 情感极性
- **正面**：用户表达满意、认可、推荐意愿
- **负面**：用户表达不满、失望、抱怨
- **中性**：用户客观描述，无明显情感倾向
- **混合**：同一条反馈中包含正面和负面情感（如"功能很全但太难用了"）

### 情感强度（1-5 级）
- **5 = 强烈**：极端表达（"太棒了！"/"完全无法使用！"）
- **4 = 较强**：明确表达（"非常好用"/"很不满意"）
- **3 = 中等**：一般表达（"还不错"/"有些问题"）
- **2 = 较弱**：含蓄表达（"感觉还行"/"不太方便"）
- **1 = 微弱**：暗示性表达（需从上下文推断）

### 情感指向
- 情感必须指向具体对象：功能、性能、界面、服务、价格等
- 笼统的"不满意"不是有效标注，必须明确不满意什么
- 一条混合情感的反馈需要拆分多个指向

### 判断置信度
- **高**：情感表达直接明确，无歧义
- **中**：需要结合上下文判断，有一定推理
- **低**：表达模糊、可能是反讽或文化差异，标记为"待人工复核"

## 2. NPS/CSAT/CES 评分框架

量化评分与文本情感必须交叉验证，二者矛盾时需要特别关注。

### NPS（净推荐值）分析框架
- **计算公式**：NPS = 推荐者比例(9-10分) - 贬损者比例(0-6分)
- **行业基准**：NPS > 50 优秀，30-50 良好，0-30 需改进，< 0 危险
- **关键动作**：分析推荐者和贬损者的开放文本回答，找到驱动因素
- **被动者机会**：7-8 分的被动者是转化为推荐者的最大机会池

### CSAT（客户满意度）分析框架
- **计算公式**：CSAT = (满意+非常满意人数) / 总回答人数 x 100%
- **行业基准**：CSAT > 80% 优秀，65-80% 良好，< 65% 需改进
- **触点分析**：CSAT 适合评估特定触点（注册、支付、客服），不同触点的 CSAT 对比揭示薄弱环节

### CES（客户费力度）分析框架
- **核心逻辑**：减少用户费力度比增加愉悦度对留存影响更大
- **关键信号**：反馈中包含"麻烦"、"复杂"、"找不到"、"步骤太多"等词汇

### 交叉验证规则
- NPS 高分但文本情感负面 = 用户可能惯性打高分，需关注文本中的隐忧
- NPS 低分但文本情感正面 = 用户可能对产品满意但对品牌/价格不满
- CSAT 各触点差异大 = 用户旅程中存在体验断点

## 3. 主题聚类方法

使用亲和图分析（Affinity Mapping）和主题分析（Thematic Analysis）将碎片化反馈聚类为结构化主题：

### 聚类流程
1. **开放编码**：逐条阅读反馈，标注关键词和短语
2. **轴心编码**：将相似关键词归类，形成初步主题
3. **选择编码**：合并和精炼主题，确定 5-8 个核心主题
4. **主题命名**：用具体可操作的语言命名（"页面加载超过 3 秒" > "性能差"）

### 聚类原则
- **互斥性**：一条反馈只归入一个主题
- **穷尽性**：所有反馈都能归入某个主题（可设置"其他"类别，但不超过总量的 10%）
- **粒度适中**：5-8 个主题最佳。少于 5 个过于笼统，多于 10 个过于碎片
- **可操作性**：主题命名应指向可改进的方向，而非抽象的概念

### Kano 模型辅助分类
将聚类后的主题进一步用 Kano 模型分类：
- **基本需求（Must-be）**：用户认为理所当然，没有会不满，有了不会特别满意（如"登录能正常使用"）
- **期望需求（Performance）**：满足程度越高越满意，线性关系（如"加载速度越快越好"）
- **兴奋需求（Attractive）**：用户没有期望但提供后会惊喜（如"智能推荐恰好是我想要的"）
- **无差异需求（Indifferent）**：有无皆可，不影响满意度
- **反向需求（Reverse）**：有了反而不满意（如"强制弹窗教程"）

## 4. 趋势分析方法

情感数据的纵向变化比横截面更有价值：

### 时间序列分析
- 追踪各主题的反馈量和情感极性随时间的变化
- 标注关键事件节点（版本发布、营销活动、竞品动态、舆情事件）
- 区分趋势（持续性变化）和波动（一次性事件）

### 变化检测
- **突增**：某主题反馈量突然上升，通常与特定事件相关
- **突降**：某主题反馈量突然下降，可能是问题已修复或用户已放弃
- **渐升**：某主题反馈量缓慢增长，可能是结构性问题在积累
- **渐降**：某主题反馈量缓慢减少，可能是自然衰减或替代方案出现

## 5. 反情感分析陷阱

以下是情感分析中常见的误判模式，必须警惕：

### 常见陷阱
| 陷阱 | 描述 | 应对 |
|------|------|------|
| 反讽误判 | "真是太'好用'了" 被判为正面 | 结合上下文和标点符号判断 |
| 文化差异 | 中文用户倾向于含蓄表达，负面情感可能被低估 | 对"还行""一般""凑合用"保持警觉 |
| 幸存者偏差 | 只有不满的用户才发声 | 对比沉默的大多数的行为数据 |
| 锚定效应 | 第一印象主导后续判断 | 逐条独立标注，不受前几条影响 |
| 频率幻觉 | 同一个用户在多个渠道重复反馈，被计为多条 | 去重后再统计 |
| 表达强度偏差 | 极端表达的少数人掩盖了温和的大多数 | 同时关注频次和强度 |
