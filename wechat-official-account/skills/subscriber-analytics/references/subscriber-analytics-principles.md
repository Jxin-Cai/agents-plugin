# 数据分析方法论

本文档定义了微信公众号数据分析的核心方法论，包括关键指标定义、分析方法和改进建议生成框架。

---

## 1. 关键指标定义和基准值

### 一级指标（北极星指标）

| 指标 | 定义 | 计算公式 | 优秀基准 | 行业平均 |
|------|------|---------|---------|---------|
| 净增关注 | 一定周期内的关注净增长 | 新关注 - 取关 | >推送数x50/次 | 视号而定 |
| 头条打开率 | 头条推文的打开比例 | 头条阅读量 / 送达量 | >15% | 5-8% |
| 单篇平均阅读 | 每篇推文的平均阅读量 | 总阅读量 / 推文数 | >关注数x10% | >关注数x3% |

### 二级指标（过程指标）

| 指标 | 定义 | 优秀基准 | 说明 |
|------|------|---------|------|
| 分享率 | 分享量 / 阅读量 | >5% | 衡量内容的传播力 |
| 收藏率 | 收藏量 / 阅读量 | >3% | 衡量内容的价值密度 |
| 完读率 | 读完全文人数 / 打开人数 | >50% | 衡量内容吸引力和篇幅控制 |
| 互动率 | (评论+点赞) / 阅读量 | >2% | 衡量用户参与度 |
| 取关率 | 推送后取关数 / 推送送达数 | <1% | 衡量内容匹配度 |
| 二次传播系数 | 二次阅读量 / 分享量 | >3 | 衡量分享后的传播效率 |

### 三级指标（诊断指标）

| 指标 | 用途 |
|------|------|
| 送达率 | 实际送达 / 关注数，检查是否有大量僵尸粉 |
| 朋友圈打开占比 | 从朋友圈入口的阅读占比，衡量内容的社交传播力 |
| 搜一搜来源占比 | 从微信搜索入口的阅读占比，衡量 SEO 效果 |
| 次条阅读衰减率 | 次条阅读 / 头条阅读，衡量多图文的吸引力分配 |
| 评论情感分布 | 正面/中性/负面评论比例，衡量内容口碑 |

## 2. 分析方法

### 同比分析

比较相同时间周期的数据：
- **周同比**：本周 vs 上周
- **月同比**：本月 vs 上月
- **年同比**：今年同期 vs 去年同期

**使用场景：** 排除周期性波动（如周末效应），判断长期趋势。

**注意事项：**
- 节假日会造成异常波动，同比时需标注
- 公众号重大事件（如爆款文章、被投诉）会影响数据可比性

### 环比分析

比较相邻时间周期的数据：
- **日环比**：今天 vs 昨天
- **周环比**：本周 vs 上周
- **推送环比**：本次推送 vs 上次推送

**使用场景：** 快速判断短期变化方向。

### 群组分析（Cohort Analysis）

按关注时间将订阅者分组，追踪各组的行为差异：

```
关注月份 → 7日留存 → 30日留存 → 90日留存 → 活跃度
2026-01    85%       70%        55%        中
2026-02    82%       65%        50%        中
2026-03    90%       78%        —          高
```

**使用场景：** 判断新关注用户的质量趋势。如果近期新关注用户的留存率在上升，说明获客质量在改善。

### 归因分析

追踪每篇文章的效果归因：

```
文章A（标题党风格） → 高打开率 + 高取关率 = 负面
文章B（干货长文）   → 中打开率 + 高完读率 + 高收藏率 = 正面
文章C（互动投票）   → 中打开率 + 高互动率 + 低取关率 = 正面
```

### 漏斗分析

分析从曝光到深度互动的转化漏斗：

```
送达（100%）
  ↓ 打开率
阅读（X%）
  ↓ 完读率
读完全文（Y%）
  ↓ 互动率
点赞/评论/分享（Z%）
  ↓ 转化率
行动（关注/购买/注册）（W%）
```

每个环节的流失都是优化机会：
- 打开率低 → 优化标题和封面
- 完读率低 → 优化内容质量和排版
- 互动率低 → 优化 CTA 设计
- 转化率低 → 优化行动引导

## 3. 内容表现评估框架

### 四象限分类

按打开率和分享率将文章分为四类：

```
        高分享率
           |
    传播型  |  爆款型
    (低打高分) | (高打高分)
  ---------+----------
    低效型  |  标题型
    (低打低分) | (高打低分)
           |
        低分享率
    低打开率 ← → 高打开率
```

| 类型 | 特征 | 行动 |
|------|------|------|
| 爆款型 | 高打开 + 高分享 | 复制成功要素，打造系列 |
| 传播型 | 低打开 + 高分享 | 标题需要优化，内容质量好 |
| 标题型 | 高打开 + 低分享 | 标题吸引但内容未达预期 |
| 低效型 | 低打开 + 低分享 | 选题或时机需要反思 |

### 文章生命周期分析

公众号文章的阅读量随时间衰减：

```
推送后 1h：获得 30-40% 的总阅读
推送后 4h：获得 60-70% 的总阅读
推送后 24h：获得 85-90% 的总阅读
推送后 72h：获得 95%+ 的总阅读
```

**异常模式识别：**
- 24h 后仍有大量增量 → 可能被搜一搜收录，或有二次传播
- 1h 内阅读量异常低 → 可能推送时段不佳

### 系列文章分析

如果有系列文章（多篇相关主题），分析：
- 系列内各篇的阅读量趋势（递增 = 系列成功，递减 = 疲劳）
- 系列对关注增长的贡献
- 系列最佳篇数（通常 3-5 篇为一个系列）

## 4. 改进建议生成方法

### STAR 建议框架

每条建议使用 STAR 格式：

```
Situation（现状）：当前指标是什么状态？
Task（目标）：要达到什么目标？
Action（行动）：具体要做什么？
Result（预期结果）：执行后预期的改善幅度？
```

**示例：**

```
现状：头条打开率当前 6%，低于行业平均 8%
目标：3 个月内提升到 12%
行动：
  1. 每篇文章准备 3 个标题候选，选择最强的
  2. 标题必须包含数字或问句
  3. 将推送时间从早 8 点调整到晚 8 点
  4. 每周分析打开率最高的文章，提取标题共性
预期：每项优化预计贡献 1-2% 的打开率提升
```

### 建议优先级矩阵

```
        高影响
           |
    重要不紧急 |  紧急重要
    (规划执行)  | (立即执行)
  -----------+-----------
    不重要    |  紧急不重要
    (暂缓/不做) | (快速处理)
           |
        低影响
    低紧急 ← → 高紧急
```

### 反模式建议清单

以下"建议"没有价值，必须避免：

| 反模式 | 问题 | 修正 |
|--------|------|------|
| "提高内容质量" | 不可操作 | "每篇文章增加 1 个数据来源引用" |
| "增加互动" | 不具体 | "每篇文末增加一个投票选项" |
| "优化标题" | 模糊 | "使用数字型标题公式，如'5个技巧...'" |
| "提高发布频率" | 可能适得其反 | "从每周 1 篇提升到每周 2 篇，观察 4 周取关率变化" |
| "学习竞品" | 无方向 | "分析竞品 TOP3 文章的标题结构，提取可复用的公式" |

### 目标设定方法

使用阶梯式目标：

```
当前打开率：6%
  → 第1月目标：8%（+2%，低垂果实：优化标题和推送时间）
  → 第2月目标：10%（+2%，进阶优化：个性化内容）
  → 第3月目标：12%（+2%，深度优化：粉丝分层推送）
```

每个阶梯对应具体的优化动作，而不是一步到位。
