# 关键指标定义与基准值

---

## 1. 一级指标（北极星指标）

| 指标 | 定义 | 优秀基准 | 行业平均 |
|------|------|---------|---------|
| 净增关注 | 新关注 - 取关 | >推送数x50/次 | 视号而定 |
| 头条打开率 | 头条阅读量 / 送达量 | >15% | 5-8% |
| 单篇平均阅读 | 总阅读量 / 推文数 | >关注数x10% | >关注数x3% |

## 2. 二级指标（过程指标）

| 指标 | 定义 | 优秀基准 | 说明 |
|------|------|---------|------|
| 分享率 | 分享量 / 阅读量 | >5% | 传播力 |
| 收藏率 | 收藏量 / 阅读量 | >3% | 价值密度 |
| 完读率 | 读完人数 / 打开人数 | >50% | 吸引力+篇幅 |
| 互动率 | (评论+点赞) / 阅读量 | >2% | 参与度 |
| 取关率 | 推送后取关 / 送达数 | <1% | 内容匹配度 |
| 二次传播系数 | 二次阅读量 / 分享量 | >3 | 传播效率 |

## 3. 三级指标（诊断指标）

| 指标 | 用途 |
|------|------|
| 送达率 | 检查僵尸粉比例 |
| 朋友圈打开占比 | 社交传播力 |
| 搜一搜来源占比 | SEO 效果 |
| 次条阅读衰减率 | 多图文吸引力分配 |
| 评论情感分布 | 内容口碑 |

---

## 4. 内容四象限分类

按打开率和分享率将文章分为四类：

| 类型 | 特征 | 行动 |
|------|------|------|
| 爆款型 | 高打开 + 高分享 | 复制成功要素，打造系列 |
| 传播型 | 低打开 + 高分享 | 标题需优化，内容质量好 |
| 标题型 | 高打开 + 低分享 | 标题吸引但内容未达预期 |
| 低效型 | 低打开 + 低分享 | 选题或时机需反思 |

---

## 5. 文章生命周期

```
推送后 1h：30-40% 总阅读 | 4h：60-70% | 24h：85-90% | 72h：95%+
```

**异常模式**：24h 后仍有大量增量 → 可能被搜一搜收录；1h 内异常低 → 推送时段不佳。
