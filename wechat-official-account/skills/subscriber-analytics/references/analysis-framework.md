# 分析方法与改进框架

---

## 1. 分析方法

### 同比分析

比较相同周期数据（周同比、月同比、年同比），排除周期性波动。
注意：节假日和重大事件会影响可比性，需标注。

### 环比分析

比较相邻周期（日环比、推送环比），快速判断短期变化方向。

### 群组分析（Cohort）

按关注时间分组，追踪各组的留存和活跃度差异：

```
关注月份 → 7日留存 → 30日留存 → 90日留存
```

判断新关注用户的质量趋势。

### 归因分析

追踪单篇文章的综合效果：

| 模式 | 指标组合 | 评价 |
|------|---------|------|
| 标题党 | 高打开 + 高取关 | 负面 |
| 干货文 | 中打开 + 高完读 + 高收藏 | 正面 |
| 互动文 | 中打开 + 高互动 + 低取关 | 正面 |

### 漏斗分析

```
送达(100%) → 打开(X%) → 读完(Y%) → 互动(Z%) → 转化(W%)
```

每个环节的流失都是优化机会：打开低→优化标题，完读低→优化内容，互动低→优化 CTA。

## 2. STAR 建议框架

每条改进建议必须包含：

| 要素 | 说明 | 示例 |
|------|------|------|
| Situation | 当前指标状态 | 头条打开率 6%，低于行业平均 8% |
| Task | 要达到的目标 | 3 个月内提升到 12% |
| Action | 具体要做什么 | 每篇准备 3 个标题候选；标题含数字或问句；推送时间调整到晚 8 点 |
| Result | 预期改善幅度 | 每项优化贡献 1-2% 打开率提升 |

---

## 3. 反模式建议清单

以下"建议"无价值，必须避免：

| 反模式 | 修正 |
|--------|------|
| "提高内容质量" | "每篇文章增加 1 个数据来源引用" |
| "增加互动" | "每篇文末增加一个投票选项" |
| "优化标题" | "使用数字型标题公式" |
| "提高发布频率" | "从每周 1 篇提升到 2 篇，观察 4 周取关率" |
| "学习竞品" | "分析竞品 TOP3 文章标题结构" |

---

## 4. 阶梯式目标设定

```
当前打开率 6%
  → 第1月：8%（低垂果实：优化标题和推送时间）
  → 第2月：10%（进阶：个性化内容）
  → 第3月：12%（深度：粉丝分层推送）
```

每个阶梯对应具体优化动作，不一步到位。
