# 文章结构与写作规范

---

## 1. 公众号文章黄金结构

```
开头钩子（100-150字）→ 核心论点 1-3（论据+案例）→ 总结升华（100-200字）→ CTA（50-100字）
```

### 开头钩子类型

| 类型 | 适用场景 | 示例 |
|------|---------|------|
| 痛点共鸣 | 解决方案型 | "每次看到个位数阅读量，你是不是也想过放弃？" |
| 数据冲击 | 分析/观点型 | "90% 的公众号在第 3 个月就停更了。" |
| 故事引入 | 案例/经验型 | "上个月，500 粉丝小号单篇破 10 万。" |
| 提问激发 | 知识/教程型 | "为什么有的号打开率 30%，有的只有 3%？" |
| 反常识 | 观点/争议型 | "日更其实在伤害你的公众号。" |

### 正文组织原则

- **SCQA 框架**：情境 → 冲突 → 问题 → 答案
- **总分总**：核心观点 → 分论点展开 → 收束总结
- **递进式**：问题 → 原因 → 方案 → 实操步骤
- **对比式**：误区 → 正确做法 → 效果对比

## 2. 标题写作

### 高效标题公式

| 公式 | 模板 |
|------|------|
| 数字型 | `{N}个{方法}，让你的{目标}{提升}` |
| 对比型 | `{A}和{B}的区别，90%的人都搞错了` |
| 结果型 | `{时间}内{结果}，我只用了{方法}` |
| 清单型 | `{领域}必备的{N}个{工具/方法}` |

### 标题自检清单

- 字数 20-30 字？
- 包含核心关键词？
- 有明确的价值承诺？
- 无诱导、无夸大、无违规词？
- 在订阅号列表中显示完整？

---

## 3. CTA 设计原则

| CTA 类型 | 适用场景 | 示例 |
|---------|---------|------|
| 关注引导 | 新用户可能看到的文章 | "觉得有用？关注我，每周分享干货" |
| 分享引导 | 高价值/高共鸣内容 | "如果有启发，分享给需要的朋友" |
| 评论互动 | 观点型/讨论型 | "你怎么看？欢迎评论区说说想法" |
| 行动号召 | 教程/工具型 | "现在就打开后台，试试第 3 个方法" |

**原则**：自然过渡、价值互换、低门槛、不强迫。一次只放一个 CTA。
