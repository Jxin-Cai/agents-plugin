# 文章创作规范

本文档定义了微信公众号文章创作的最佳实践，涵盖结构设计、移动端优化、标题写作、CTA 设计和排版规范。

---

## 1. 公众号文章结构最佳实践

### 黄金结构

```
开头钩子（100-150字）
    ↓
核心论点 1 + 论据 + 案例
    ↓
核心论点 2 + 论据 + 案例
    ↓
核心论点 3 + 论据 + 案例
    ↓
总结升华（100-200字）
    ↓
CTA 行动号召（50-100字）
```

### 开头钩子类型

| 类型 | 适用场景 | 示例开头 |
|------|---------|---------|
| 痛点共鸣 | 解决方案型文章 | "每次打开后台，看到个位数的阅读量，你是不是也想过放弃？" |
| 数据冲击 | 分析/观点型文章 | "90% 的公众号在第 3 个月就停更了。" |
| 故事引入 | 案例/经验型文章 | "上个月，一个只有 500 粉丝的小号，单篇阅读破了 10 万。" |
| 提问激发 | 知识/教程型文章 | "同样的内容，为什么有的公众号打开率 30%，有的只有 3%？" |
| 反常识 | 观点/争议型文章 | "日更其实在伤害你的公众号。" |

### 正文组织原则

- **SCQA 框架**：情境(Situation) → 冲突(Complication) → 问题(Question) → 答案(Answer)
- **总分总**：核心观点 → 分论点展开 → 收束总结
- **递进式**：问题 → 原因分析 → 解决方案 → 实操步骤
- **对比式**：误区展示 → 正确做法 → 效果对比

### 结尾收束

- 总结核心要点（不超过 3 个）
- 给出可立即行动的下一步
- 自然引导互动（提问/投票/留言）

## 2. 移动端阅读优化

### 核心数据

- 95% 的公众号阅读发生在手机上
- 平均阅读时长 3-5 分钟
- 用户滑动速度：每秒约 2 屏
- 首屏留存率决定了是否继续阅读

### 段落规范

| 规则 | 标准 | 原因 |
|------|------|------|
| 段落长度 | 2-4 行（手机约一屏） | 长段落造成视觉压迫 |
| 句子长度 | 不超过 30 字 | 手机屏幕宽度有限 |
| 段间距 | 每段之间空一行 | 呼吸感，减少阅读疲劳 |
| 连续文字 | 不超过 3 段纯文字 | 必须插入视觉元素打断 |

### 视觉层次工具

1. **小标题（H2/H3）**：每 300-500 字一个小标题
2. **加粗**：每段 1-2 处关键信息加粗
3. **引用块**：突出核心观点或数据
4. **有序/无序列表**：3 个以上并列信息用列表
5. **分割线**：大章节过渡使用
6. **图片**：每 500-800 字至少一张配图

### 信息密度 vs 阅读体验

在公众号中，信息密度需要让步于阅读体验：

- 一个观点说一段，不要一段塞多个观点
- 重要数据单独成行或加粗强调
- 用"空白"制造节奏感——适当的留白不是浪费空间

## 3. 标题公式和 AB 测试

### 高效标题公式

#### 数字型
- `{数字}个{方法/技巧}，让你的{目标}{提升/改善}`
- `做到这{数字}点，{痛点}不再是问题`

#### 对比型
- `{A}和{B}的区别，90%的人都搞错了`
- `别再{错误做法}了，试试{正确做法}`

#### 结果导向型
- `{时间}内{达成结果}，我只用了{方法}`
- `{人物}是如何{达成结果}的？`

#### 清单型
- `{领域}必备的{数字}个{工具/方法}`
- `2026年{领域}趋势盘点`

### AB 测试方法

1. 为同一文章准备 2-3 个候选标题
2. 标题之间只改变一个变量（数字/情感/结构）
3. 记录每个标题公式的历史打开率
4. 积累数据后，为本号找到最佳标题公式

### 标题自检清单

- [ ] 字数 20-30 字之间？
- [ ] 包含核心关键词？
- [ ] 有明确的价值承诺（读者能获得什么）？
- [ ] 无诱导、无夸大、无违规词？
- [ ] 在订阅号消息列表中显示完整？

## 4. CTA 设计原则

### CTA 类型

| CTA 类型 | 适用场景 | 示例 |
|---------|---------|------|
| 关注引导 | 新用户可能看到的文章 | "觉得有用？关注我，每周分享{主题}干货" |
| 分享引导 | 高价值/高共鸣内容 | "如果这篇对你有启发，分享给同样需要的朋友吧" |
| 评论互动 | 观点型/讨论型内容 | "你怎么看？欢迎在评论区说说你的想法" |
| 行动号召 | 教程/工具型内容 | "现在就打开你的后台，试试第 3 个方法" |
| 转化引导 | 推广型内容（10%比例） | "点击阅读原文，了解更多" |

### CTA 写作原则

1. **自然过渡**：CTA 是文章的自然延伸，不是突然的推销
2. **价值互换**：告诉读者"做这个动作能获得什么"
3. **低门槛**：一个简单的动作（点赞/分享/留言），不要多个 CTA 同时出现
4. **不强迫**：用邀请语气而非命令语气

### 反模式

- "不转不是中国人" — 诱导分享，违规
- "点赞、转发、收藏三连" — 贪心 CTA，效果反而差
- "快来关注我们吧！！！" — 语气过于急切，降低品牌调性
- 在文章中间突然插入广告 — 打断阅读体验

## 5. 排版规范

### 字号规范

| 元素 | 推荐字号 | 说明 |
|------|---------|------|
| 正文 | 15-16px | 手机阅读最舒适 |
| 标题 | 18-20px | 适度突出 |
| 注释/来源 | 12-13px | 辅助信息 |

### 行距和间距

| 元素 | 推荐值 | 说明 |
|------|-------|------|
| 行距 | 1.75-2.0 倍 | 手机端需要更大行距 |
| 段间距 | 15-20px | 段落间的呼吸感 |
| 字间距 | 1-2px | 微调可提升阅读舒适度 |

### 配色方案

| 场景 | 推荐方案 |
|------|---------|
| 正文颜色 | #3f3f3f（深灰，比纯黑更柔和） |
| 强调颜色 | 品牌主色（如 #1a73e8） |
| 引用块背景 | #f7f7f7（浅灰背景） |
| 分割线 | #e5e5e5（浅灰线条） |
| 链接/重点 | 品牌主色 |

### Markdown 到微信的注意事项

- 外部链接在微信中不可点击，需转为底部引用格式
- 代码块需要特殊样式适配（微信编辑器不原生支持语法高亮）
- 表格在手机端可能过窄，超过 3 列建议改用列表
- 图片宽度自动适应屏幕，无需指定宽度
- GIF 动图支持，但文件大小需控制在 2MB 以内
