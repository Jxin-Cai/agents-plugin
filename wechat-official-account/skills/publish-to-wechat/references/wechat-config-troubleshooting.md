# 配置与故障排查

---

## 1. 凭证获取步骤

1. 访问 https://mp.weixin.qq.com 并登录
2. 进入 **设置与开发** → **基本配置**
3. AppID 直接显示；AppSecret 需点击"重置"生成
4. **IP 白名单**：必须将调用 API 的服务器 IP 添加到白名单

---

## 2. EXTEND.md 配置模板

```markdown
# 微信公众号配置

## 账号信息
- 公众号名称：{名称}
- 公众号类型：订阅号 / 服务号
- 认证状态：已认证 / 未认证

## 发布偏好
- 默认主题：default
- 主色调：#1a73e8
- 默认作者：{作者名}
- 默认字号：16px
- 默认行距：1.75
- 启用评论：否
- 启用赞赏：否
```

---

## 3. 浏览器方式要点

- 首次使用需扫码登录，Cookie 有效期约 24 小时
- 编辑器入口：`https://mp.weixin.qq.com/cgi-bin/appmsg?t=media/appmsg_edit&action=edit&type=77`
- 通过 `browser_evaluate` 注入 HTML 内容到编辑器
- 保存草稿后截图确认

---

## 4. API 故障排查

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| access_token 失败 | IP 未加白名单 | 后台 → 基本配置 → IP 白名单 |
| 草稿失败 45008 | 内容超字数限制 | 拆分为多篇文章 |
| 草稿失败 45005 | 内容含外链 | 检查 HTML 中的 `<a>` 标签 |
| 图片上传失败 | 格式/大小不符 | 转 JPG，压缩到 10MB 内 |
| 封面图上传失败 | 超过 2MB | 压缩图片 |

---

## 5. 内容格式故障排查

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 样式丢失 | 用了外部 CSS | 改用内联 style |
| 图片不显示 | 外部图片 URL | 上传到微信素材库 |
| 链接不可点击 | 外链限制 | 转底部引用格式 |
| 代码块异常 | 微信不支持语法高亮 | 纯文本样式代码块 |
| 表格异常 | 列数过多 | 3 列以上改用列表 |
