# 微信 HTML 内容格式规范

---

## 1. 白名单标签

**文本**：`<p>`, `<span>`, `<strong>`, `<b>`, `<em>`, `<i>`, `<u>`, `<s>`, `<del>`, `<sub>`, `<sup>`, `<br>`
**结构**：`<div>`, `<section>`, `<h1>`-`<h6>`, `<blockquote>`, `<pre>`, `<code>`, `<hr>`
**列表**：`<ul>`, `<ol>`, `<li>`
**表格**：`<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`
**媒体**：`<img>`, `<video>`（仅微信视频）

**禁止**：`<script>`, `<link>`, `<style>`, `<iframe>`, `<form>`, `<a href>` 外链

---

## 2. Markdown 转微信 HTML 映射

| Markdown | 微信 HTML |
|----------|----------|
| `# 标题` | `<h2>` 带主色调样式（微信中 h1 过大） |
| `## 小标题` | `<h3>` 带主色调样式 |
| `**加粗**` | `<strong style="color:{主色调}">` |
| `> 引用` | `<blockquote>` 带左边框 + 浅灰背景 |
| `- 列表` | `<ul><li>` 带行距样式 |
| `` `代码` `` | `<code>` 浅灰背景 + 红色字 |
| 代码块 | `<section><pre><code>` 灰色背景圆角 |
| `---` | `<hr>` 浅灰细线 |

---

## 3. 外部链接处理（关键）

微信公众号不支持外部链接点击，必须转换为底部引用格式：

1. 扫描所有 `[text](url)` 格式链接
2. 每个外链分配编号 `[1]`, `[2]`
3. 正文替换为 `文本<sup>[1]</sup>`
4. 文末添加引用链接列表
5. 微信认证号的公众号文章链接可保留超链接

---

## 4. 外链限制

| 公众号类型 | 外链能力 |
|-----------|---------|
| 未认证订阅号 | 不支持任何外链 |
| 已认证订阅号 | 仅"阅读原文"一个入口 |
| 已认证服务号 | 公众号文章互链 + "阅读原文" |

**通用策略**：所有外链一律转底部引用格式。

---

## 5. 图片和表格处理

- 图片 URL 必须是 mmbiz.qpic.cn 域名
- 本地图片和外部图片需先上传到微信素材库
- 表格超过 3 列改用键值对列表（手机端过窄）

---
