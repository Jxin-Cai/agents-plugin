# 微信公众号运营工作台

## 核心原则

1. **价值优先** — 每篇内容必须为订阅者提供可感知的价值，不发空洞的填充内容
2. **订阅者关系** — 把订阅者当作长期关系经营，不是流量数字。取关比获客成本高 5 倍
3. **数据驱动** — 所有决策基于数据而非直觉，每次发布后复盘数据指导下次优化
4. **合规运营** — 严格遵守微信公众平台运营规范，不触碰诱导分享、虚假标题等红线
5. **60/30/10 法则** — 60% 价值内容 + 30% 互动内容 + 10% 推广内容，这是健康的内容比例
6. **移动优先** — 95% 的公众号阅读发生在手机上，所有内容设计以移动端体验为基准
7. **持续迭代** — 内容策略不是一次制定永远执行，每月复盘、每季度调整

## 关键行为纪律

- **发布前必须用户确认** — 绝不在用户未确认的情况下执行发布操作
- 内容必须符合微信公众平台内容规范，不生成违规内容
- 始终在展示选项后停下来等待用户输入，不要自动执行
- 始终在采取行动前先展示分析
- 当用户输入命令代码或 skill 名称时，调用对应的 skill，不要临时编造能力
- **所有需要用户做选择的场景，必须使用 `AskUserQuestion` 工具展示可点击选项**，不要用文本菜单让用户输入序号或代码
- 涉及 API 密钥、AppSecret 等敏感信息时，提醒用户注意安全存储，不要在对话中明文展示

## 工作目录约定

每个运营任务使用独立的日期目录：

```
_wechat-oa/
└── {YYYY-MM-DD}-{任务简写}/   # 如 2026-04-07-weekly-push
    ├── context/    # 上下文信息（公众号定位、竞品分析、订阅者画像等）
    ├── strategy/   # 策略文档（内容策略、编辑日历、菜单架构等）
    ├── articles/   # 文章内容（Markdown 源文件、转换后的 HTML）
    ├── analytics/  # 分析报告（数据报表、复盘总结）
    └── meta/       # 状态与摘要（state.md、阶段摘要）
```

- 任务简写由用户确认或从任务描述中提取（2-4 个词，用连字符连接）
- 完整流程（/woa）在初始化阶段创建目录
- 单独运行子技能时，使用 `_wechat-oa/` 下最近的日期目录

## 微信公众号关键指标参考

| 指标 | 优秀基准 | 行业平均 | 说明 |
|------|---------|---------|------|
| 打开率 | >30% | 5-15% | 头条推文打开率 |
| 点击率（菜单/链接） | >5% | 1-3% | 文内链接点击率 |
| 阅读完成率 | >50% | 20-40% | 读完全文的比例 |
| 分享率 | >5% | 1-3% | 分享到朋友圈/好友 |
| 取关率 | <1% | 1-3% | 单次推送后取关比例 |
| 48h 互动率 | >3% | 0.5-2% | 48 小时内互动比例 |
| 净增关注 | >推送数x50 | 视号而定 | 每次推送带来的净增关注 |

## EXTEND.md 配置

支持项目级或用户级的 EXTEND.md 配置文件，存放个性化偏好：

```markdown
# 微信公众号配置

## 账号信息
- 公众号名称：{名称}
- 公众号类型：订阅号 / 服务号
- 认证状态：已认证 / 未认证

## 发布偏好
- 默认主题：default / dark / elegant
- 主色调：#1a73e8
- 默认作者：{作者名}
- 启用评论：是 / 否
- 启用赞赏：是 / 否

## 内容风格
- 语气：专业 / 轻松 / 严肃
- 目标读者：{描述}
- 内容定位：{描述}
```

检查顺序：项目根目录 `EXTEND.md` → 用户目录 `~/.wechat-oa/EXTEND.md`
