# 响应式设计原则

---

## 1. 移动优先

- 使用 `min-width` 媒体查询从小屏向大屏增强，禁止 min/max 混用
- 基础样式（无媒体查询时）= 移动端样式，先确保 320px 正常
- **反模式**：桌面设计后"缩小适配" / `display: none` 隐藏大量内容 / 仅一个 `max-width: 768px` 断点

---

## 2. 内容驱动断点

断点在**内容开始看起来不对的地方**设置，非特定设备宽度。

| 区间 | 范围 | 场景 |
|------|------|------|
| xs | 320-375px | 小屏手机 |
| sm | 376-480px | 普通手机 |
| md | 481-768px | 平板竖屏 |
| lg | 769-1024px | 平板横屏 / 小笔记本 |
| xl | 1025-1440px | 桌面 |
| 2xl | 1441px+ | 大屏 |

**断点治理**：统一断点变量集中定义 / 新增需正当理由 / 不超过 6 个 / 组件级响应式优先用 Container Queries

---

## 3. 弹性布局

### 布局技术

| 场景 | 推荐 |
|------|------|
| 一维排列（行/列） | Flexbox |
| 二维网格 | CSS Grid |
| 页面骨架 | Grid（宏）+ Flex（微） |
| 等宽列 | `repeat(auto-fill, minmax(min, 1fr))` |

### 尺寸单位

| 属性 | 推荐 | 避免 |
|------|------|------|
| 字体 | rem, clamp() | 固定 px |
| 间距 | rem, em | — |
| 容器宽度 | %, max-width | 固定 px |
| 行高 | 无单位（1.5） | px |

- **弹性字体**：`clamp(1rem, 0.5rem + 2vw, 1.5rem)`
- **溢出防护**：`overflow-wrap: break-word` / 长 URL 用 `word-break: break-all` / 小屏表格横向滚动或卡片化

---

## 4. 触控适配

| 规则 | 标准 |
|------|------|
| 触控目标最小尺寸 | 48x48px（WCAG 2.5.8） |
| 目标间距 | >= 8px |
| Hover 替代 | `@media (hover: hover)` 分离 hover / touch |
| 手势冲突 | 水平滑动不与浏览器前进/后退冲突 |

---

## 5. 图片与媒体

- **响应式图片**：`srcset` + `sizes` 按视口选择尺寸，`<picture>` 用于艺术指导
- **格式优先级**：AVIF > WebP > JPEG > PNG > SVG（图标）
- **CLS 防护**：`<img>` 必须声明 `width` / `height` 或用 `aspect-ratio`，动态内容预留占位
- **懒加载**：非首屏图片 `loading="lazy"` + `decoding="async"`

---

## 6. 审计快检清单

| 检查项 | 通过标准 |
|--------|---------|
| 无水平滚动 | 320-2560px 任何宽度无水平滚动条 |
| 文本可读 | 320px 下 body >= 16px |
| 触控目标 | 按钮/链接 >= 48x48px |
| 图片自适应 | 图片不溢出容器 |
| 导航可用 | 320px 下所有导航项可达 |
| 表单可用 | 输入框不溢出，键盘不遮挡 |
| 断点过渡 | 过渡平滑无跳变 |
