## Step 1: 确定审计范围

如果 `$ARGUMENTS` 非空，以此作为审计目标的初始输入。

向用户确认审计范围：

- **目标**：审计哪些页面/组件？（文件路径或 URL）
- **关注端**：主要关注哪些端？（移动端 / 平板 / 桌面端 / 全部）
- **已知问题**：是否有已知的响应式问题？

使用 Glob 扫描 `src/**/*.{css,scss,less}` 和 `src/**/*.{tsx,jsx,vue,svelte}` 获取样式与组件文件列表。使用 Grep 搜索 `@media` 和 `@container` 提取断点定义，搜索 `breakpoint|screen` 定位断点变量声明。Read 断点配置文件（`tailwind.config.*` / `variables.scss` / `theme.ts`）。

**⏸️ 等待用户确认后继续。**

## Step 2: 断点策略审计

使用 Grep 搜索 `@media\s*\(` 提取全部媒体查询，搜索 `min-width|max-width` 统计查询方向分布，Read 断点变量定义文件：

#### 2a. 断点一致性

- 项目是否有统一的断点变量/token 定义？
- 是否存在散落的硬编码断点值？
- 媒体查询方向是否统一？（推荐 min-width 移动优先，不要 min/max 混用）
- 是否有重叠或遗漏的断点区间？

#### 2b. 断点合理性

- 断点值是否基于内容需要？
- 是否覆盖了关键视口范围：
  - 小手机：320px - 375px
  - 普通手机：376px - 480px
  - 平板竖屏：481px - 768px
  - 平板横屏 / 小笔记本：769px - 1024px
  - 桌面：1025px - 1440px
  - 大屏：1441px+
- 是否使用了 Container Queries 处理组件级响应式？

**向用户展示断点地图和发现的问题。**

## Step 3: 布局弹性审计

检查布局系统的弹性：

#### 3a. 布局技术

- 是否使用了现代布局（CSS Grid / Flexbox）？
- 是否有残留的 float 布局或固定宽度布局？
- Grid 和 Flex 的使用是否合理？（Grid 用于二维布局，Flex 用于一维排列）

#### 3b. 尺寸单位

- 是否使用了弹性单位？（rem、em、%、vw/vh、clamp()）
- 是否有硬编码的 px 宽度导致小屏溢出？
- 最大宽度（max-width）是否合理设置？
- 字体大小是否使用了 clamp() 或响应式缩放？

#### 3c. 溢出检查

- 是否存在任何视口宽度下的水平滚动条？
- 长文本是否正确处理？（text-overflow、word-break）
- 表格在小屏下的处理策略？（横向滚动 / 卡片化 / 折叠列）

#### 3d. 现代 CSS 特性

- 是否使用了 Container Queries（`@container`）实现组件级响应式？
- 是否使用了 CSS Nesting 简化媒体查询嵌套？
- 是否利用了 `:has()` 选择器替代部分 JS 逻辑判断？
- 是否使用了 `@layer` 管理样式优先级层叠？

## Step 4: 触控与交互适配

检查移动端触控体验：

- 所有可交互元素的触控目标 >= 48x48px？
- 触控目标之间的间距 >= 8px？
- hover 效果是否有 touch 替代方案？（`@media (hover: hover)`）
- 是否有仅依赖 hover 的交互？（如 tooltip、下拉菜单）
- 滑动手势是否不与浏览器默认手势冲突？

## Step 5: 图片与媒体响应式

检查图片和媒体资源的响应式处理：

- 是否使用了 `srcset` / `<picture>` 按视口加载不同尺寸的图片？
- 图片是否有明确的宽高比（aspect-ratio）避免 CLS？
- 是否使用了现代图片格式（WebP / AVIF）并提供降级？
- 视频/嵌入内容是否有响应式容器？
- 是否实现了懒加载（loading="lazy"）？

## Step 6: 问题汇总与分级

将所有发现整理为分级报告：

```markdown
## 响应式审计报告

### 断点策略评估
- 当前断点方案：{描述}
- 评估：{优/良/需改进}

### Critical（必须修复）
- [ ] {文件路径}:{行号} — {问题描述} — {修复建议}

### Warning（建议修复）
- [ ] {文件路径}:{行号} — {问题描述} — {修复建议}

### Info（可选优化）
- [ ] {文件路径}:{行号} — {问题描述} — {优化建议}

### 亮点
- {做得好的地方}
```

向用户展示报告。
