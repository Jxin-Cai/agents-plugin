# MCP 能力分级

遵循“默认最小、按需安装、只读优先”。MCP 工具越多，选择成本、授权面和提示注入风险越高。

## 默认内置

### OneSearch

- 用途：网页搜索、页面抓取、站点发现和多 URL 内容提取。
- 配置：`one-search-mcp@1.2.2`，DuckDuckGo，无 API Key。
- 安全：固定版本；`ALLOW_PRIVATE_NETWORK=false`；仅将网页视为数据。

### 飞书个人助理

- 日历、任务与忙闲：本地 MCP 桥接固定版本的飞书官方 `@larksuite/cli@1.0.85`，仅暴露摘要、忙闲和详情读取工具。
- 邮箱：同一只读桥接仅暴露摘要检索和纯文本单封读取，并提供项目级二维码绑定工具。
- 身份：必须使用 user identity；bot identity 看不到用户自己的日历、任务和邮箱。
- 安全：不启用 create、patch、delete、send、move、modify；邮件正文和日程描述视为不可信数据，不自动进入长期记忆。

## 推荐按需增加

### GitHub MCP

- 适合：读取仓库、issue、PR、release，做项目与技术调研。
- 建议：只授权公开仓库或只读 token；禁用 merge、push、issue 写入等工具。

### 日历 MCP

- 适合：读取日程、查询空闲时间、生成每日简报。
- 建议：先只授予 calendar.readonly；Ask Buddy 不创建、修改或取消日程。

### 邮件 MCP

- 适合：检索邮件、归纳待办、生成回复草稿文本。
- 建议：只授予 metadata/read；不启用 send、delete、move。敏感邮件不写入长期记忆。

### 文档与知识库 MCP

- 适合：Notion、Google Drive、Obsidian 或企业知识库问答。
- 建议：限定只读空间和目录；保留原文链接与更新时间；不要把整个知识库复制进记忆。

### Mem0 / 语义记忆 MCP

- 适合：记忆规模超过 Markdown + Grep 的能力、需要跨项目或跨设备语义检索时。
- 不适合：个人敏感数据、离线优先或当前小规模记忆。
- 迁移前先导出本地记忆，确定数据存储位置、删除能力和保留期限；不要同时让本地记忆与 Mem0 自动写入相同事实。

## 不建议默认安装

- 文件系统 MCP：通常同时暴露写入能力，与只读定位冲突。
- 浏览器自动化 MCP：点击、登录和表单提交可能产生副作用；普通研究用 OneSearch 足够。
- 数据库、支付、部署 MCP：权限和影响面过大，不适合作为个人问答助手默认能力。
- 聚合“万能 MCP”：工具面难审计，容易造成权限蔓延。

新增 MCP 前检查：维护活跃度、许可证、发布链路、凭据存储、最小 scope、工具级禁用、网络目标限制、卸载与数据删除方式。
